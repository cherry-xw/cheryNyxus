# 前端 UI 人工复核详情

目录入口：[已知问题](./README.md)。本文件只记录尚未由用户在实际界面确认的前端 UI 项；代码级测试通过不等于这些项目通过。

自动执行者不得启动或操控浏览器/Electron，不得截图、录屏、像素比对或运行浏览器 UI 自动化。以下结论由用户在实际宿主中给出；无法覆盖的环境应记录为未验证。

## FE-UI-001 双主题与渲染效果待人工复核

- 模块：主题、Element Plus、Teleport 弹层、Nyxus Canvas。
- 类型/状态：人工复核 / 待用户复核。
- 优先级：P2。
- 当前证据：颜色对比度、主题传播、层级常量和 Canvas 调色板已有代码级测试；尚无用户实际渲染结论。
- 影响：若宿主合成、局部样式或真实窗口层级与代码假设不同，可能仍出现低对比、弹层遮挡或主题不同步。
- 处理决定：当前不继续自动 UI 自测，等待用户复核。

人工复核范围：

1. 在浅色和深色下查看正文、说明、输入值、按钮、选中项、错误提示及禁用态是否清晰。
2. 打开 `/`、`@`、角色、路由和确认类弹层，确认 Teleport 内容始终位于当前窗口上方。
3. 查看 Nyxus 节点、边、标签和选中态，并在界面打开期间切换主题。
4. 在两个同源浏览器窗口或相关原生窗口间切换主题，确认同步且没有循环闪烁。

通过与关闭条件：用户确认上述实际渲染无阻断问题；未覆盖的宿主明确记录。发现问题时将本项改为“已确认待修复”，并为具体模块拆出新 ID。

定位入口：主题规则见 [前端 UI 规范](../../standards/frontend/ui-visual-and-interaction.md)；代码入口为 [theme.ts](../../../web/src/stores/theme.ts) 的 `toggle/applyFrom`、[theme.css](../../../web/src/styles/theme.css) 的主题 token、[overlayLayers.ts](../../../web/src/styles/overlayLayers.ts) 的 `OVERLAY_Z_INDEX` 和 [ExecutionGraphPixiRenderer.ts](../../../web/src/features/pets/nyxus/renderer/ExecutionGraphPixiRenderer.ts) 的主题调色板应用。

## FE-UI-002 关键交互反馈待人工复核

- 模块：设置、桌面窗口、会话草稿与附件、Workbench 分支。
- 类型/状态：人工复核 / 待用户复核。
- 优先级：P1。
- 当前证据：保存快照、关闭分支、附件归属、上传竞态、ACK 清理、重试和分支限制已有自动测试；真实窗口中的信息是否足以让首次用户判断尚未确认。
- 影响：如果反馈呈现仍不清晰，用户可能误判保存状态、丢弃草稿、重复创建分支或把附件理解为已发送。
- 处理决定：当前不继续自动 UI 自测，等待用户使用安全测试数据复核。

人工复核范围：

1. 修改设置后分别测试保存、放弃、继续编辑、保存失败、保存中继续修改和外部修订。
2. 从页面、窗口标题栏和系统关闭入口检查有/无草稿时的关闭策略；最小化不得丢草稿。
3. 在不同会话间切换文字与附件草稿，覆盖慢上传、取消、失败重试和连续发送。
4. 在 Workbench 分支中确认不支持的附件会在发送前说明；创建成功但刷新失败时不会提示为创建失败。

通过与关闭条件：用户能够仅凭界面判断已保存/未保存内容、附件归属、动作影响和恢复方式。发现具体问题后改为“已确认待修复”并按设置、窗口、Composer 或 Workbench 拆出新 ID。

定位入口：[设置中心](../../frontend/settings.md)、[桌面工作区](../../frontend/desktop-cyber-workspace.md)、[多窗口工作台](../../frontend/workbench-multi-window.md)。

## FE-UI-003 登录与多输入方式待人工复核

- 模块：登录连接、首次进入、键盘、触摸、小视口和操作反馈。
- 类型/状态：人工复核 / 待用户复核。
- 优先级：P2。
- 当前证据：连接等待、防重复提交、键盘语义和窄布局已有代码级回归；实际可发现性、焦点顺序、触摸可达性与阅读体验尚未由用户确认。
- 影响：首次用户可能无法判断下一步，键盘或触摸用户可能无法到达关键操作，小窗口可能裁掉必要上下文。
- 处理决定：当前不继续自动 UI 自测，等待用户复核。

人工复核范围：

1. 覆盖首次打开、已有配置、保存密码已失效、断连、连接失败和重试，确认状态与下一步明确。
2. 仅用键盘完成设置页签、Nyxus 会话选择/删除、弹层确认/取消和主要表单提交。
3. 用触摸或不依赖 hover 的方式完成主要操作，确认重要说明存在点击、聚焦或固定入口。
4. 在约 1280×720、768×1024、390×844 和应用最小窗口查看设置、资源工作台、会话列表与输入区。
5. 检查空数据、长标题、多会话、加载失败、剪贴板失败和正常启动诊断反馈。

通过与关闭条件：用户确认主要任务无需开发者解释即可完成，焦点可见且顺序合理，关键输入与确认操作在目标视口可达。发现问题后按登录、资源、会话或响应式布局拆出新 ID。

定位入口：[登录与连接](../../frontend/auth-login.md)、[桌面工作区](../../frontend/desktop-cyber-workspace.md)、[Nyxus 节点树](../../frontend/pet/nyxus-node-tree-maintenance.md)。
