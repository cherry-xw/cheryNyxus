# 验证说明

> 状态：强制执行。

本目录维护当前可复用的验证方法、适用范围、已知限制和必要人工核对入口，不保存 AI 开发过程、历次修复、临时阶段、调度记录或已作废决策。功能与协议事实由对应模块的权威文档维护。

## 内容要求

- 按功能或验证主题组织，不按开发任务、执行轮次或历史版本组织。
- 验证说明提供实际存在的命令、测试入口、检查目标、成功条件与运行前提。
- 当前验证状态区分自动检查、实际部署和人工验收；未执行或无法确认的项目明确标注，不由源码存在推导验证通过。
- 当前未解决问题记录位置、影响和解决条件；解决后更新现状，不保留修复流水。
- 示例、计划新增路径和实际实现入口必须明确区分，不能把不存在的文件作为现有验证入口。

## 记录与收口

长期文档仅保留仍适用的验证说明和当前结论。原始运行输出、历史审批原文和开发追踪保存在仓库外的运行记录或任务系统中，不要求复制到 Markdown，也不以历史记录归档作为计划收口条件。

活动计划依据[计划规范](../../standards/documentation/plans.md)维护当前目标、未完成事项及验收条件。必要验证和用户审批仍须实际完成；清除历史过程不代表验证已经通过。

## 人工核对

视觉、交互、主观体验和需要真实设备的检查由用户执行，遵守[项目协作规范](../../standards/global/ai-collaboration.md)。未获明确授权，不启动浏览器、读取图片或执行 DOM/CSS 自动验收。

## 维护规则

调整内容时同步当前索引与引用。既有文档必须按本规范更新为现状；不因位于历史目录而获得保留过期规则或开发流水的例外。删除纯历史文件前确认其中没有独有的当前事实、操作入口或尚未解决问题，并同步移除入链。
