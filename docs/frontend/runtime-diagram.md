# Agent 运行头部与结果节点树

本文是工作台图形展示的目标契约。执行事实归 [workflow 协议](../shared/protocol/workflow.md)，后端层级归 [中间件](../backend/agent/middleware.md)，实施状态归 [活动计划](../plan/main-agent-runtime-diagram/README.md)。

## 1. 结构与边界

采用带阶梯轮廓的嵌套布局，层级为 Loop → 内容记录（checkpoint）→ 工具（sense）→ 重试（retry）→ 模型（chat）。向内调用靠左、返回及后处理靠右，各层按节点和布线需要分配空间，不强制对称。连线清楚是硬性条件：先满足不穿节点/文字、不产生含混交叉或重叠，再减少转折和占地。外框直角、细边界、主题浅底；中文至少 12px，正文 400、标题至多 600。

唯一 activeBranchId 的主分支展示完整头部；其他分支与子 Agent 使用标准简略节点。结果树仍使用 canonical 内容投影、稳定 lane、显式关系和内容锚点，只有消息、工具、派发、返回、分支、过程组等结果；内部 occurrence 不生成结果节点。Vue Flow 单画布/单相机；当前卡牌、阅读、审批动作与偏好冻结，不恢复 Pixi。结果历史不为头部腾空间，头部按完整可见包围盒向右避让。

## 2. 全部连接关系

下表的连续箭头表示独立关系；条件和供给不表示必然执行。层边界端口不是执行步骤，不新增后端事件。

| 区域 | 关系 |
| --- | --- |
| 接入 | 输入接收 → 排队 → 本轮入口 → 消费；有指令时消费 → 指令注入；消费或注入后进入内层 |
| 请求 | 上下文构建/恢复 → 请求准备（供给）；请求准备 → 模型 → 响应；通道说明关联模型而非串行阶段 |
| 返回 | 响应 → 内容记录（文本/摘要）或调用清单（工具）；内容记录 → 继续判断 |
| Loop | 判断 → 本轮入口（下一轮）、等待或结束；等待 → 实际唤醒 → 本轮入口；暂停/取消/中断只读控制事实 |
| 重试 | 模型 → 错误判断；可恢复 → 退避 → 请求准备；耗尽/不可恢复 → 失败终态；不重新执行整个 Loop |
| 工具 | 清单 → 参数校验 → 权限校验 → 审批判断；需要 → 审批，无需 → 预检；通过 → 预检 → 执行 → 结果 → 内容记录 |
| 异常 | 参数/权限/审批拒绝/预检/执行失败 → 拒绝或失败结果 → 工具结果；共享结果收集通道不表示等待所有来源 |
| 续接 | 工具续接 → 重建清单及适用校验/授权/审批链，跳过模型；已失效工具 → 工具结果，不直接跳过授权到预检 |
| 协作 | 执行 → 派发 → 子执行摘要 → 回传 → 父接收；父接收仅凭明确关系连接唤醒或实际消费，不强制进入等待 |
| 压缩 | 请求准备 → 压缩请求 → 摘要生成 → 实际采用 → 请求准备；未采用不强调返回路径 |
| 结果树 | canonical 的 sequence/continue/spawn/dispatch/return/return-continuation/fork-continuation/fork-detail 及现有展示连接保留；结果末端 → 对应头部 |
| 选择 | 步骤 → 内容仅在显式锚点定位时临时显示，不长期重复铺线 |

模型流式内容可在调用未结束时向外归集。工具清单按 callId 区分同名调用，共用一套处理链；清单顺序不制造因果。没有独立事件的节点显示未单独记录；状态只按 kind/reason/waitReason 与显式 anchor 匹配，不匹配自由文本。运行、轮次、尝试和调用隔离，终态保留；祖先仅显示内层活动，不伪造自身执行。局部失败不推导 run 失败。

## 3. 递归折叠与路由

任意运行层都可手动收起：所有后代、内部线、调用清单和实时面板隐藏，父层成为标准尺寸、仅含标题的单节点；状态可用边框反馈，摘要只在展开/详情可见。展开恢复后代原先选择。整个头部也可收起。

原始节点映射到当前可见代表（自身或实际可见的折叠祖先）。每条原始边保留身份：映射后端点不同就继续显示；两端同属折叠父层则作为隐藏内部关系保留，不画自环。不同收起父层之间的边不可删除。同端点、同方向和同类关系可聚合，保留成员与每个成员的证据；不因一个成员执行而把所有关系标成执行过。

端口按方向及关系固定排序。左右为进入/返回，局部条件与外围回路使用分离通道；工具异常收集、重试、Loop、压缩和协作不混用路径。正交路径、端口、箭头和标签统一；线不得穿节点和文字，不同语义不得无标记共线。必要跨线使用明确断口，不冒充汇合。路由空间不足时扩展通道，不能删除关系、降低字体或隐藏失败线。

默认跟随运行：展开活动层及必要祖先，用户手动收起优先，不会被事件打开；手动覆盖按 root/header/layer 隔离，跨轮次保留。当前焦点和正在操作的详情阻止自动收起；显式定位展开必要祖先。一轮结束保留最后构图。提供跟随运行、展开全部、收起头部与定位当前步骤。

## 4. 信息、相机与动画

展开节点显示名称、状态、关键摘要；完整参数/结果/错误和实例历史由现有阅读器或只读步骤详情读取。无锚点不按时间猜关联。轮次与尝试分别标注，未知总数不显示进度分母。模型可见且运行时显示固定尺寸实时窗口，正文内滚动，提供可用通道和回到最新；模型或祖先收起时窗口一并隐藏，终态/回放不挂载 live 窗口。

折叠布局一次计算代表节点、端口与新路由，再由 GSAP 统一过渡。子图向父节点收拢，外线端点同时重接；拓扑不同使用绑定各自端点的新旧路径淡入淡出，不能悬空。约 280ms、可中断反向、无排队；reduced 即时布局与短淡入。生命周期按 [动效规范](motion-standard.md)，后台/断线/切 root/回放/卸载清理。执行标记仅按有因果证据的 live 增量沿真实路径移动；hydrate 不补播。Morphicons 沿现有例外仅负责图标形变。

相机按 root 保留，普通增量和展开不自动 fit，不重排结果历史；窄窗口平移与显式定位，不缩小字号。图内按钮、滚动和详情阻止画布串扰；标题、展开、说明与详情具有键盘路径和焦点恢复。

## 5. 实现与验证入口

[RuntimeDiagram.vue](../../web/src/features/agent/workbench/runtime-diagram/RuntimeDiagram.vue) 连接 controller 与选择；[graphModel.ts](../../web/src/features/agent/workbench/runtime-diagram/graphModel.ts) 的 projectWorkflowGraph 适配同一 Vue Flow。纯模板与状态通过 headerTemplate/headerState 定义，headerGraph 构建头部，纯层级/可见关系/布局计算在组件外完成。数据流为语义图 → 递归折叠 → 节点布局 → 通道及端口 → 展示；不在组件里临时删除边或猜端点。

内部展示接口维护层父子关系、展开覆盖、可见代表、聚合成员、端口、路径及布局版本；RPC/schema/journal 不变。扩展节点时同步层归属、关系表、证据匹配和布局验证。

定向 Vitest 覆盖关系守恒、五层全部 32 种折叠设置、两个折叠父层的连接、路由穿透/标签/端口、工具异常/续接、重试/Loop、交错协作、压缩、gap、root/回放及动画清理。验证入口：pnpm test:web、pnpm web:type-check、受影响 ESLint、pnpm web:build。最终自动与人工清单唯一维护在活动计划，旧通过不能替代新契约验收。浏览器/Electron 操作及视觉验收由用户执行，正常 p95 ≤20ms、压力 p95 ≤33ms。
