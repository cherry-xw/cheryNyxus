# Agent 运行头部与结果节点树

本文是工作台图形展示的目标契约。执行事实归 [workflow 协议](../shared/protocol/workflow.md)，后端层级归 [中间件](../backend/agent/middleware.md)，实施状态归 [活动计划](../plan/main-agent-runtime-diagram/README.md)。

## 1. 结构与边界

采用 XY 平面内原位伸展的递归芯片封装：展开后父层、外围步骤和子层同时存在，内层撑开父封装，形成洋葱圈式包裹；收起后恢复单颗元器件与对外引脚。禁止以切换单板或 Z 轴叠片替代多层共存。层级为 Loop 调度器 → 内容记录（checkpoint）→ 工具（sense）→ 重试（retry）→ 模型（chat）；后四项才是 defaultHandlers 中的四层中间件。输入资源在总览，压缩属于模型封装，协作属于工具封装，展示归属不改后端执行身份。中文至少 12px，正文 400、标题至多 600。

唯一 activeBranchId 的主分支展示完整头部；其他分支与子 Agent 使用标准简略节点。结果树仍使用 canonical 内容投影、稳定 lane、显式关系和内容锚点，只有消息、工具、派发、返回、分支、过程组等结果；内部 occurrence 不生成结果节点。Vue Flow 单画布/单相机；当前卡牌、阅读、审批动作与偏好冻结，不恢复 Pixi。结果历史不为头部腾空间，头部按完整可见包围盒向右避让。

## 2. 全部连接关系

下表的连续箭头表示独立关系；条件和供给不表示必然执行。层边界端口不是执行步骤，不新增后端事件。

| 区域 | 关系 |
| --- | --- |
| 接入 | 输入接收 → 排队 → 本轮入口 → 消费；有指令时消费 → 指令注入；消费或注入后进入内层 |
| 请求 | 上下文构建/恢复 → 请求准备（供给）；请求准备 → 模型 → 响应；通道说明关联模型而非串行阶段 |
| 返回 | 响应 → 内容记录（文本/摘要）或调用清单（工具）；内容记录 → 继续判断 |
| Loop | 判断 → 本轮入口（下一轮）、等待或结束；等待 → 实际唤醒 → 本轮入口；暂停/取消/中断只读控制事实 |
| 重试 | 模型 → 错误判断；可恢复 → 退避 → 请求准备；耗尽/不可恢复 → 失败终态；不重新执行整个 Loop |
| 工具 | 清单 → 参数校验 → 权限校验 → 审批判断；需要 → 审批，无需 → 预检；通过 → 预检 → 执行 → 结果 → 内容记录 |
| 异常 | 参数/权限/审批拒绝/预检/执行失败 → 拒绝或失败结果 → 工具结果；共享结果收集通道不表示等待所有来源 |
| 续接 | 工具续接 → 重建清单及适用校验/授权/审批链，跳过模型；已失效工具 → 工具结果，不直接跳过授权到预检 |
| 协作 | 执行 → 派发 → 子执行摘要 → 回传 → 父接收；父接收仅凭明确关系连接唤醒或实际消费，不强制进入等待 |
| 压缩 | 请求准备 → 压缩请求 → 摘要生成 → 实际采用 → 请求准备；未采用不强调返回路径 |
| 结果树 | canonical 的 sequence/continue/spawn/dispatch/return/return-continuation/fork-continuation/fork-detail 及现有展示连接保留；结果末端 → 对应头部 |
| 选择 | 步骤 → 内容仅在显式锚点定位时临时显示，不长期重复铺线 |

模型流式内容可在调用未结束时向外归集。工具清单按 callId 区分同名调用，共用一套处理链；清单顺序不制造因果。没有独立事件的节点显示未单独记录；状态只按 kind/reason/waitReason 与显式 anchor 匹配，不匹配自由文本。运行、轮次、尝试和调用隔离，终态保留；祖先仅显示内层活动，不伪造自身执行。局部失败不推导 run 失败。

## 3. 递归折叠与路由

封装按独立展开集合控制；展开父层不会隐藏其他层或兄弟节点。递归先测量内部尺寸，再按列宽、行高和布线间距向外排版，节点拖拽保持锁定。外部线路接芯片边缘引脚，内板对应引脚与内部线路在同一坐标接续，保留完整原始关系。调用清单和实时面板随所属封装展开，整个头部仍可收起。

原始节点映射到自身或当前板可见的子封装。跨板边使用成对接口端子，保留原始关系 ID、方向、条件、来源、去向及独立执行证据；端子可追踪另一端并定位到其所属板。端子只是展示接口，不产生执行事件。不在当前板呈现的内部关系和外部关系分别记账，不能丢边或伪造自环。

单板所有可见线路零交叉、零重叠、不穿元件/文字，不使用过孔、跨线桥或无标记断口。先按连接关系摆放相邻元件，再按稳定关系顺序分配独立引脚，优先直线及少折角短路径。候选路径必须通过全段障碍及已有线路检查才提交；无法满足时用明确编号的成对端子接续，不静默退回冲突路径。端子详情给出完整关系与条件；路由、端子和面板均纳入板尺寸。

默认跟随运行：活动步骤的所有祖先自动展开，并聚焦当前执行区域；并发活动层共存，步骤结束后无活动的层自动收起。只有活动身份或展开几何改变才调整视野，正文流式增量不触发相机。手动展开、收起、选择历史或移动画布暂停跟随，显式恢复跟随重新读取当前事实。回放、断线、后台、切 root 和卸载取消待执行相机任务；手动展开集合按 root/header 隔离。缩放阈值只展开或收起一层，外围始终保留。

## 4. 信息、相机与动画

节点主体只显示名称与状态图标，以语义颜色区分状态；去掉“尚未发生”、覆盖率和重复轮次等摘要。说明由明显的信息按钮在节点上方展开，不用原生 title 承载说明；完整参数/结果/错误和实例历史由现有阅读器或只读步骤详情读取。无锚点不按时间猜关联。轮次与尝试在头部选择器呈现。模型可见且运行时显示固定尺寸实时窗口，正文内滚动，提供可用通道和回到最新；模型或祖先收起时窗口一并隐藏，终态/回放不挂载 live 窗口。

折叠布局一次计算代表节点、端口与新路由，再由 GSAP 统一过渡。子图在封装与内部板之间缩放收拢；切层期间隐藏线路，元件到位后显示新板的已验证线路，避免中间帧穿透或交叉。约 280ms、可中断反向、无排队；reduced 即时布局与短淡入。生命周期按 [动效规范](motion-standard.md)，后台/断线/切 root/回放/卸载清理。执行标记仅按有因果证据的 live 增量沿真实路径移动；hydrate 不补播。Morphicons 沿现有例外仅负责图标形变。

相机按 root/header/板保留；首次显式进入定位到板内起点并保持可读缩放，返回恢复原视野，普通增量不自动 fit、不重排结果历史。窄窗口平移与显式定位，不缩小字号。图内按钮、滚动和详情阻止画布串扰；标题、进入、返回、接口追踪与详情具有键盘路径和焦点恢复。

## 5. 实现与验证入口

[RuntimeDiagram.vue](../../web/src/features/agent/workbench/runtime-diagram/RuntimeDiagram.vue) 连接 controller 与选择；[graphModel.ts](../../web/src/features/agent/workbench/runtime-diagram/graphModel.ts) 的 projectWorkflowGraph 适配同一 Vue Flow。纯模板与状态通过 headerTemplate/headerState 定义，headerGraph 构建头部，纯层级/可见关系/布局计算在组件外完成。数据流为语义图 → 当前板及封装代表 → 局部布局 → 稳定引脚与短路径/端子接续 → 展示；不在组件里临时删除边或猜端点。

内部展示接口维护层父子关系、当前板、可见代表、关系成员、端子、端口、路径和模板版本；RPC/schema/journal 不变。布局由 `headerLayout.layoutHeader` 与 `headerBoardRouting.routeBoardEdges` 维护；`useHeaderBoardNavigation` 持有导航、相机和接口追踪。扩展节点时同步层归属、板内位置、关系表、证据匹配和全部板布局验证。

定向 Vitest 覆盖全部 9 张板的关系守恒、封装边界映射、逐层进入/返回和 root 隔离、路由穿透/标签/端口、工具异常/续接、重试/Loop、交错协作、压缩、gap、root/回放及动画清理。验证入口：pnpm test:web、pnpm web:type-check、受影响 ESLint、pnpm web:build。最终自动与人工清单唯一维护在活动计划，旧通过不能替代新契约验收。浏览器/Electron 操作及视觉验收由用户执行，正常 p95 ≤20ms、压力 p95 ≤33ms。
