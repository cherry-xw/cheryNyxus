# 前端通用规范边界

本页只维护仍有效的职责与规范路由，不保存裁决过程或已作废规则。

## 视图与数据职责

视图、Controller和Presenter职责以[Vue规范](vue3-page-building-standard.md)为准。数据与用例经明确的公共入口提供，不建立重复事实来源；不为凑层级创建只透传属性的容器。

## 目录与依赖

目录按职责、依赖权限、变更轴和公共边界组织，不规定每目录固定文件数量。目录与依赖由[Web架构规范](web-frontend-architecture.md)维护，Vue规范只负责组件职责与质量。尚未采用的框架不能写成强制门禁。

Feature的状态和I/O访问均经application公共入口；过渡适配入口必须显式导出并维护边界，不能直接穿透到任意store或service。

## 主题与动画

主题使用深色电光青和浅色靛蓝的双极强调色，通过主题token统一管理。模块独立调色板须明确说明例外，不作为全局第二套主题来源。

DOM动画使用GSAP；Pixi画布动画和CSS动画按各自职责管理。性能、减少动画偏好和质量调整遵守[设计语言](design-language.md)，不能根据某个模块的当前行为推导全局例外。
