# 开发规范（Standards）

> 本目录集中存放项目**强制执行的开发规范**。所有新增、修订、裁决的规范细节**必须落入本目录**，任何代码变更（含 AI 辅助开发）均须遵守。

## 强制规范操作准则声明（Operation Policy）

本声明即日起生效，对**所有开发者与 AI 协作工具**具有约束力：

1. **强制遵守**：本目录下的规范是 Code Review 与任务执行的前置约束，违反即 Review 不通过；
2. **文档先行**：新增或修改规范，必须先更新本目录文档并确认边界，再开始代码修改（纯格式化、纯重命名等不改变语义的改动可豁免）；
3. **唯一归集**：后续任何规范细节（新规范、修订、裁决记录）一律落入 `docs/standards/`，禁止散落在其他目录或仅存于对话中；
4. **冲突仲裁**：规范间冲突以"高内聚、低耦合、易扩展 + 5 秒定位"为最高原则，裁决结果记录于 [裁决记录](./decisions.md)；
5. **渐进迁移**：新代码强制，存量代码触碰即整改，不要求一次性重构；
6. **工具链强制**：可机器检查的规范项必须落地为 ESLint / CI 规则，不靠自觉。
