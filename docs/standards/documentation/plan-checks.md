# 计划静态检查与差异展示

本文件维护检查契约与使用场景；生命周期由[计划规范](plans.md)维护。通用工具仅依赖 Node.js 20 及以上版本，命令行与页面共用一份检查源码，不运行计划中记录的命令，不修改文档、不自动删除文件。

## 使用场景

| 时机 | 操作与目的 |
| --- | --- |
| 建立、移动、删除或更改任务状态后 | 运行静态检查，发现漏登记、重复登记、状态冲突和失效引用 |
| 更新当前步骤、准备交接或提交前 | 检查计划和当前记录一致；同时人工核对授权与下一步是否仍真实 |
| 进入验收和最终删除前后 | 检查必要材料、引用及临时文件位置；用户审批不由脚本代替 |
| 自动集成检查 | 以退出码阻止基础错误进入共享分支，不忽略错误以追求全绿 |
| 用户查看 Plan 页面 | 展示入口登记、实际目录与小任务文件差异，跳转相关文档查看两边值 |
| 发布通用包 | 构建单文件工具、运行相关测试，解压后对样例与错误数据检查，核对包清单 |

通用命令：`node tools/lint.mjs --plan-dir=<计划目录>`；增加 `--json` 返回同一结构化报告，`--strict` 使待核对项也返回失败。页面运行 `node tools/plan-viewer.mjs --plan-dir=<计划目录>`。仓库使用自身配置的命令入口。

退出码：0 表示无阻断错误；1 表示存在阻断错误（严格模式也包括待核对项）；2 表示参数或执行失败。普通模式仍完整输出待核对项，不能把“无阻断错误”解释为验收通过。

## 比较规则

| 类别 | 阻断错误 | 待核对项 |
| --- | --- | --- |
| 导航 | 根入口缺失、孤立表格行、任务目录漏登记、重复登记、登记目标不是直属任务 README | 无 |
| 状态 | 总任务状态非法、入口和任务状态不一致、台账与小任务明确状态冲突 | 非执行资料缺少任务元信息时不强制推断身份 |
| 台账 | 进行中或阻塞的拆分小任务无文件；完成项仍链接实施文件；声明进度与台账统计不同；明确 ID 依赖缺失或形成循环 | 没有台账且没有单页标记、创建时间缺失、无法自动判断的依赖正文 |
| 引用 | 实际 Markdown 本地链接的文件或章节不存在、越出项目边界、符号链接越界 | 未从任务 README 可达的 Markdown 文件；需核对是否仍有用途 |
| 恢复 | 无法自动证明正文真实 | 缺少当前恢复检查点，或出现多个恢复点；需要执行者合并、核实 |
| 文件位置 | 计划根散放文件；运行日志、缓存或输出放在任务资料区；一次性脚本不在 verify | 未知用途文件需人工分类，不自动删除 |
| 审批准备 | 待审批任务仍有未完成台账项、缺少结论表或有未通过的验证项 | 脚本不能证明用户实际批准、需求已完成或长期内容已完整迁出 |

目录数与任务数比较的是任务目录和入口条目，不机械要求全部 Markdown 数量等于小任务数。设计、参考资料和手册允许存在；远期未开始任务可无独立文件。统计分别显示登记任务、实际目录、台账关联小任务文件、磁盘小任务文件和其他文档，并报告具体差异。

执行小任务以台账链接、文档顶部的标准小任务状态或 `文档类型：小任务` 识别；参考资料可标 `文档类型：参考资料`，正文历史示例中的状态不作为文件身份。未登记的标准小任务仍报告错误。

带 ID 的依赖检查使用台账 `ID` 列与 `依赖 ID` 列，依赖值为现有 ID，用逗号或顿号分隔，无依赖写“无”。普通 `依赖` 列可以保留说明与权威链接，脚本不从自然语言猜测任务关系。

## 页面呈现与修正

总览列出入口与磁盘任务的并集，未登记或缺文件的任务仍可见。显示实际统计与检查时间，并提供全部、阻断错误、待核对筛选。任务详情显示入口状态和文档状态、小任务文件数量及具体差异。

每项差异包含规则编号、严重程度、位置、预期值、实际值与修正建议。可读文档提供跳转入口；文件缺失时仍显示缺失路径。颜色只辅助表达，不能替代文字。刷新重新读取磁盘，不缓存旧报告；不提供猜测状态的自动修复或删除按钮。

## 责任与边界

检查源码唯一维护于工具的 `audit.mjs`，页面 API、CLI 和项目检查均消费相同报告；发布构建把它与解析器打入单文件工具。报告固定包含 `summary`、`plans`、`issues`；每项问题包含 `code`、`severity`、`plan`、`path`、`line`、`expected`、`actual`、`message`、`action`。调用方不得另造一套状态枚举。

只检查计划目录及其明确引用，不全仓读取业务代码或第三方依赖。正文中的无链接路径、命令语义、接口真实消费者与文件用途仍需按变更对象搜索核对；静态脚本不能保证任意自然语言记录及时更新。临时文件的仓库外清理责任由任务记录维护，不扫描个人目录或凭据。测试与运行产物不读图。
