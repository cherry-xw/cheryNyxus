# 文档管理方案采用指南

> 状态：采用指南，不定义规则；规则归属见[包入口](README.md#文件与规则归属)。

本指南帮助新项目采用同目录的通用规则包。[需求设计规范](requirements-design.md)维护场景分析、调研、方案选择与交接方法；[内容规范](./content.md)、[结构规范](./structure.md)和[计划规范](./plans.md)维护文档与计划规则；[统一入口模板](./entry-template.md)提供启动基线和项目配置必填项。本指南只维护采用与评估流程。

## 1. 复制范围

整体复制本目录为目标项目的 `docs/standards/documentation/`，包括 README、需求设计及内容/结构/计划规范、检查说明、入口模板、指南和独立工具。保留包内相对链接。将模板合入目标项目根 `AGENTS.md`，替换项目配置区；不要覆盖目标项目已有有效约定。

各工具配置其支持的入口读取根 `AGENTS.md`，统一维护规则正文。用新会话验证入口是否被加载，不假设所有工具都自动识别同一文件名。

## 2. 配置项目

1. 确认实际源码、测试根和稳定业务边界，只为实际需要的领域建立 README。
2. 在统一入口的项目配置区直接列出任务范围、领域职责和真实 README 链接，使首次定位无需枚举目录。范围未知时使用文档总索引。
3. 按[统一入口模板](./entry-template.md)项目配置区的必填项逐项填写。
4. 统一入口按触发操作直接链接通用规范与项目协作规范，规定在相关操作开始前读取；需求分析方法引用通用说明，项目只维护自身执行权限和审批政策。
5. 文档总索引保留完整领域导航，并指定维护者同步统一入口中的稳定路由。
6. 如果项目存在生成文档或外部来源镜像，先登记源文件、输出目录、来源版本和同步命令，再把检查接入项目命令；不存在时明确登记“无”。

## 3. 迁移现有文档

老项目没有文档或现有文档无法可靠导航时，先执行[存量项目梳理指南](./existing-project-guide.md)，建立经过验证的最小入口。已有结构基本可用时，再盘点各主题的事实 owner，核实契约与实现证据并合并重复定义。通用规则归规则包，业务事实归模块，项目特殊限制归项目配置或其引用的协作政策。

旧路径被引用时可在权威页面保留必要锚点；单一跳转页与兼容跳转页的处理按[内容规范](./content.md)第 5 节和第 5.1 节。不能同时保留两份规则正文，也不能把生成输出或外部镜像当成第二个事实源。移动或删除文件时按[结构规范](./structure.md)第 4 节同步导航与入链。长期知识从历史计划迁入正式文档，过程按项目保留政策清理。

先选择一个高频模块，补齐任务意图、权威说明、实现路径、关键符号和验证入口。其余模块随实际变更逐步治理，不要求一次性重写，也不创建没有内容的章节。

## 4. 运行检查

按[内容规范](./content.md)第 8 节的检查项运行检查，并核对统一入口的领域路由与文档总索引一致。项目选择现有工具或接入相应检查；本包提供仅依赖 Node.js 的可选[计划检查与查看器](tools/README.md)，不要求目标项目采用特定包管理器。

选几个真实任务验证：能否在操作前读到适用规则，能否直接找到模块与验证方式，是否仍需全仓搜索。结构可达不等于契约正确，内容与影响面仍需维护者评审。

按[方法效果检查](requirements-design.md#10-方法效果检查与参考来源)选择适合本项目的场景，核对方法选择、证据、用户决定及交接是否可执行。先区分文档自查与实际任务试用，后者按项目权限开展；不因采用规则包自动调用其他模型或执行实验。

基础不一致必须修正后再交接；有争议的状态、未验收的业务和未知文件用途保持真实，不能为通过检查伪造。已有计划按当前事实更新，已确认的用户授权不重复请求。

## 5. 评估与升级

记录相同任务的读取次数、跳转次数、全仓搜索次数和统一入口长度。稳定一级路由应减少首次定位操作；详细模板、低频例子和历史过程不应挤入统一入口。常见任务应满足[内容规范](./content.md)第 2 节的四跳要求。

需求与设计方法的效果按[总成本评估](requirements-design.md#9-模型分工与总成本)观察遗漏、重复纠正、返工、交接补充、耗时和费用；没有实际数据时不宣称节省比例。升级时将已有同义方法改为引用，避免项目规范与通用规范各自维护一份正文。

升级规则包时检查本地差异，将项目参数留在项目配置，更新模板新增的触发入口和必填项并重跑导航检查。包内规则相互引用，避免只复制一篇正文而遗漏依赖；修改规则时按 README 的规则归属表定位 owner 文件。

最低采用标准：统一入口可用，真实领域可直达，每项事实有唯一 owner，高频任务能定位到符号与验证，活动任务可恢复，长期知识不只存在于计划中。
