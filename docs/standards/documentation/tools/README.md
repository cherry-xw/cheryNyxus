# 计划管理工具（可选）

配合 [计划规范](../plans.md) 使用，环境依赖：Node.js ≥ 20（仅内置模块，无需 npm install），跨平台，对 `docs/plan` 只读。

两个脚本都会自动从所在位置向上逐级查找 `docs/plan` 目录；找不到时用 `--plan-dir=<目录>` 或环境变量 `PLAN_DIR` 指定。

## plan-viewer.mjs — 计划查看页面

```bash
node plan-viewer.mjs                # 默认 http://127.0.0.1:4173
node plan-viewer.mjs --port=5000    # 换端口
node plan-viewer.mjs --help         # 全部选项
```

浏览器打开后可视化查看总入口当前登记的活动计划、任务台账与完成进度；数据实时读盘，刷新即最新。批准完成的计划按规范移除入口和目录，不作为长期历史台账展示；查看器仍兼容遗留的 `已完成` 状态。服务只绑定 `127.0.0.1`。支持文档相对链接和引用式链接；章节位置保存在路由的 `anchor` 参数中，刷新与前进后退可恢复。仅最新导航请求可以更新页面。

## lint.mjs — 计划文档最低规则校验

```bash
node lint.mjs
```

规则刻意保持最少，仅两条；通过不代表计划完全符合规范：

- **R1** 总入口 `docs/plan/README.md` 任务表格的每项必须包含可解析、位于计划根内且指向实际任务 README 文件的链接；缺失或无法解析的链接报错；
- **R2** 各计划目录的 README 必须有「状态：」行。

支持内联及完整/折叠/简写引用式链接；代码围栏中的示例不参与校验。状态与进度行支持普通、加粗标签及引用块格式。违规退出码为 1，可挂 pre-commit / CI / Agent hook。状态词枚举、台账结构、进度一致性和创建时间不校验，仍需按[计划规范](../plans.md)审查。
