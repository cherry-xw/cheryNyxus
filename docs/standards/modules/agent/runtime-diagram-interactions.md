# Agent 运行图交互入口规范 v2.0

> **状态**：强制执行。
> **适用范围**：`web/src/features/pets/nyxus/**`（树模式节点交互）、`web/src/features/agent/workbench/**` 及其待处理审批与提问入口。
> **事实说明**：当前布局与实现入口见 [Agent 运行头部与结果节点树](../../../frontend/runtime-diagram.md)。

## 1. 入口所有权

1. **Info 只解释节点**：右上角 Info 图标仅在鼠标悬浮或键盘聚焦时显示节点简介，移出或失焦即关闭。点击、触摸点按不得打开、固定或切换说明，也不得打开步骤详情或待处理操作。
2. **待处理事项统一在审核窗口处理**：当前根会话的审批与提问由页面左下角 `WorkbenchAttentionSurface` 统一承载；工作台标题栏显示可点击的 `WorkbenchAttentionIndicator` 铃铛入口，入口持续硬闪（500ms 硬切换，亮 1 → 暗 0.2；`prefers-reduced-motion` 下停用闪烁、保留常驻图标），点击后打开同一个审核窗口。事项数据统一来自交互收件箱，审核窗口内完成审批和提问。
3. **节点只负责提醒与定位**：等待审批/提问的节点在等待期间持续闪烁（与精简模式一致：500ms 硬切换，亮态 1 → 暗态 0.2；`prefers-reduced-motion` 下退化为常驻静态环）。点击问号或审批节点时打开左下角统一审核窗口，不生成节点旁的第二个审批/提问窗口。提问批可以同时锚定 assistant 消息节点与 ask_user_question 问号工具节点，两个节点一起闪烁并定位到统一审核入口。普通步骤节点主体打开步骤实例详情，不得复用待处理审核行为。
4. **节点树上下文**：节点树的 hover 详情和 CRT 使用节点树自己的 anchor/layout；流程图侧栏不挂载 CRT 或审批覆盖层。流程图步骤详情必须通过其内部节点交互打开，不得把侧栏状态回写成节点树锚点。等待交互的节点不提供 hover 详情（详情由交互卡承担）。
5. **持续可见与生命周期**：当前根只要仍有一项待处理事项，对应节点就持续闪烁；最后一项进入终态后闪烁停止、交互卡自动移除、标题栏待处理图标消失。CRT 只在模型节点活动时显示：存在正在返回数据的实时 turn 时随流式增量就地累积，turn 结束或节点空闲后立即移除，不保留空闲占位；折叠只改变其锚点，不改变是否显示或其内容来源。
6. **层级**：统一审核窗口为浮层（`--nx-z-blocking-interaction`），位于页面左下角；标题栏铃铛只负责打开/关闭该窗口。节点树 CRT 随节点树 pan/zoom 更新，流程图侧栏的步骤详情只受 Vue Flow 自己的相机管理。
7. **其他根走任务中心**：其他根会话的待处理事项不提供工作台内独立入口，由任务中心聚合展示，工作台窗口标题栏/任务栏闪烁提示。当前根事项不得挂入其他根，其他根事项也不得挂入当前节点下方。
8. **根身份以时间线为准**：当前流程的待处理归属优先使用已加载时间线的 `rootChatId`，时间线尚未可用时才回退当前选中会话 ID；不得直接用选中会话 ID 将当前根事项误分到「其他根」。标题栏待处理图标计数、闪烁节点集合和交互卡必须复用同一个根身份。
9. **进入流程必须恢复状态**：工作台进入或切换到一个根流程，以及连接恢复时，必须主动刷新持久待处理收件箱。不得假设全局通知一定晚于工作台挂载；实时通知与进入时刷新共同保证闪烁节点与标题栏待处理图标出现。

## 2. 变更约束

- 不得从旧计划摘要、旧触摸方案或通用 tooltip 习惯推导 Info 点击行为；变更入口前必须先更新本规范和展示契约。
- 审批与提问必须继续共用左下角统一审核窗口；不得为节点另建第二个可提交的审核窗口。
- Info、闪烁节点与交互卡必须分别测试，不能只验证面板最终可见而忽略触发来源。
- 键盘可达性通过节点主体聚焦提供；不得以补充触摸点击为由恢复说明固定功能。

## 3. Review 清单

- [ ] 点击或触摸 Info 是否保持无动作，且不会固定说明？
- [ ] 鼠标悬浮和键盘聚焦 Info 是否仍能查看说明，移出或失焦是否关闭？
- [ ] 等待审批/提问的节点是否持续闪烁，交互完成后是否立即停止？
- [ ] 点击标题栏铃铛或闪烁节点后，左下角统一审核窗口是否出现，窗口内审批（批准/拒绝/倒计时）与提问（选项/补充/提交）是否可用？
- [ ] 节点是否只承担闪烁和定位，不生成新的节点审核弹窗？
- [ ] 手动折叠是否保持用户选择，交互卡锚定到最近可见代表节点下方？
- [ ] 模型节点空闲或 turn 结束后，CRT 是否立即移除且不保留空闲占位？
- [ ] 标题栏待处理铃铛是否只在有待处理事项时显示并闪烁，点击是否打开左下角统一审核窗口，事项完成后是否消失？
- [ ] 精简（lite）模式保留「点击待处理工具图标 → 详情抽屉」入口，工具图标持续闪烁是否不受本次改动影响？
- [ ] 当前根事项是否只以闪烁节点 + 交互卡出现；其他根事项是否只由任务中心聚合？
- [ ] 进入子会话或时间线根与选中会话不同时，当前根事项是否仍归入当前节点树？
- [ ] 待办先于工作台打开、切换根流程或断线重连时，闪烁节点与标题栏待处理图标是否无需任何手动操作即可恢复？
