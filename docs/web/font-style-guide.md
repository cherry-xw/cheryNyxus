# 前端字体字重规范

> 适用于 `web/src/` 全部 Vue 组件与样式。2026-09-05 用户重申：除标题之外严禁加粗。此前主按钮、角色值、计数、关键词及 Markdown 正文的加粗例外取消。

## 字重映射

| 用途 | 字重 |
| --- | --- |
| 页面、窗口、章节、卡片的实际标题 | 可用 `600`，不超过 `600` |
| 正文、描述、参数值、选项、输入框、字段标签、角色值、状态、计数 | `400` |
| 全部按钮，包括主按钮 | `400` |
| tooltip、popover 正文及正文中的 `b` / `strong` | `400` |
| Markdown 非标题内容，包括 `strong` | `400` |

## 判别与检查

1. 按文字用途判断，不能因使用 `b`、`strong`、`legend` 或名称含 title 就视为标题。
2. 检查 `font-weight`、`font` 简写、浏览器默认样式、父级继承及复用组件内部样式。
3. 非标题不得用 500、600、700 等字重突出显示；通过位置、留白和主题色区分信息层级。
4. 用户阅读的中文内容一律不小于 12px；正文及表单建议 13–14px，行高 1.5–1.6。
5. 存量按修改范围逐处修正，不以历史例外为新增或修改内容加粗的依据。

## 字体与主题

正文、按钮、表单沿用项目 UI 字体。等宽字体仅用于时间、标识等辅助信息，使用 `var(--font-mono)`。

使用既有字号及主题变量，不引入另一套 token。颜色与布局规则见 [UI 视觉与交互规范](../standards/ui-visual-and-interaction.md)。
