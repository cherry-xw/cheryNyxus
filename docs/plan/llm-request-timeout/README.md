## 目标与边界

全局设置单次模型请求超时，默认 10 分钟，可调整或关闭；到时切断当前请求，不把超时当成普通网络错误自动重试。截断内容可查看并带清楚的标记，但不进入后续模型上下文。任务底部上下文信息区提供统一停止入口，替换工具栏的全流程停止；精简视图展示运行中的节点等待时长，节点 1 分钟内绿、3 分钟内黄、此后由红变深并间歇抖动；有请求超时值时显示已用/上限（节点树节点不再显示计时，2026-09-28）。一次用户发送的任务等待时间 10 分钟内绿、30 分钟内黄、此后红逐渐变深。超时后的自动第二模型分析不属于本次范围，待单独定方案。视觉验收由用户负责。

用户已确认使用当前模型；选择破坏性替换旧按钮入口。现有工作区有大量未提交修改和删除，相关文件必须局部编辑，不覆盖其他工作。
