# 手动验证操作手册（workbench-session-strip）

> 前置条件：后端已启动（`pnpm dev` 或等价环境），浏览器面与 Electron 面均可运行；存在 ≥3 个当前预设会话，其中 ≥2 个可同时运行；各操作卡 ≤1 分钟。证据留存：每卡完成后在结论行注明 通过/失败/待补 fixture，截图或文字记录存 `verify/out/`。

## <a id="strip-browser"></a>卡 1：浏览器面标题栏 strip

- **入口**：浏览器单页 → 打开工作台窗（Pet 工具栏 🌳 或 Nyxus 入口）。
- **操作**：① 发起一个会话任务并观察标题栏；② hover 运行中会话的 icon；③ 等待节点从模型思考切换到工具执行再观察 icon；④ 打开另一会话后回看 strip 当前标记。
- **期望**：标题栏出现活跃会话 icon 阵列；运行中 icon = 当前节点（model=✦ / tool=对应 sense 图标，未命中回退 ⚙），上层有**半透明 loading 遮罩**（呼吸底 + spinner，底层节点 icon 仍可见）；hover 提示**三块分栏**：标题 / 用户消息（最后一次提问）/ 当前节点；**当前打开的会话**置顶入列且有底部 accent 指示条 + 高亮；待用户（needs_user）会话有 accent 脉冲点 + 外发光。
- **结论**：待执行

## <a id="strip-native"></a>卡 2：Electron 原生工作台窗 strip

- **入口**：Electron 应用 → 打开工作台原生窗（每预设一窗）。
- **操作**：① 发起任务观察 WindowFrame 标题栏；② 点击标题栏三键附近确认无遮挡；③ hover icon 查看提示。
- **期望**：标题栏 title-actions 区出现 strip；三键可正常点击；hover 提示完整。
- **结论**：待执行

## <a id="dropdown"></a>卡 3：当前预设分页下拉

- **入口**：任一工作台窗标题栏 ☰ 按钮（当前预设分页下拉，含未运行会话；strip 溢出「+N」同入口）。
- **操作**：① 打开下拉，确认只含当前预设会话（不含其他预设）；② 会话数 > 20 时翻页/加载更多；③ 观察默认第一项高亮；④ 点击一项切换会话；⑤ hover 行出现归档按钮，归档当前会话后观察自动切到最新剩余；⑥ 点击下拉外空白处关闭。
- **期望**：列表仅当前预设；分页追加不重复、无「加载更多」后不再加载；默认第一项（最近更新）高亮；点击后工作台切换且草稿保持契约不变；下拉浮层不被工作台内容遮挡（Teleport 到 body）；归档后自动切换且无剩余时清空窗口；点击外部关闭。
- **结论**：待执行

## <a id="overflow"></a>卡 4：多会话溢出折叠

- **入口**：浏览器面工作台窗。
- **操作**：同时运行 ≥3 个当前预设会话（或构造 ≥7 个活跃会话），观察标题栏。
- **期望**：icon 数不超过上限（6），超出折叠为「+N」且可展开查看全部；icon 不重叠、不溢出标题栏。
- **结论**：待执行

## <a id="reconnect"></a>卡 5：断线重连状态一致

- **入口**：浏览器面工作台窗，运行中 ≥1 会话。
- **操作**：① 断开后端连接（停止后端或断网），观察 strip 状态；② 重连。
- **期望**：重连后 strip 与下拉状态与真实会话一致（overview 快照重放）；无卡死的运行中状态残留。
- **结论**：待执行
