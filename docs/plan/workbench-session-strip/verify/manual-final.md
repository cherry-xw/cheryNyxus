# 手动验证操作卡

本手册对应新设计，原下拉与动态图标验收不再适用。由用户在实现完成后操作，当前全部待执行。

前置条件：浏览器与 Electron 可运行；准备超过快捷位容量的任务、其他预设任务、完成/失败未查看任务、超过一页且有相似标题的历史及带分支任务。各卡操作不超过一分钟；缺少数据记“待补 fixture”，不现场等待长任务。证据为用户截图或文字记录，存本任务 `verify/out/`；结论填写通过/失败/待补 fixture。

## <a id="strip"></a>标题栏

- 入口：含运行和待处理任务的工作台。
- 操作：观察任务切换步骤时的主图标；悬停并移入 tip；键盘聚焦查看信息。
- 期望：主图标不变，小运行图标轻微闪烁而非 loading；其他状态可辨认；tip 完整且可操作。
- 结论：待执行。

- 期望：快捷项不因状态换位；当前任务可辨认且不重复；无横向滚动、无窗口按钮遮挡。
