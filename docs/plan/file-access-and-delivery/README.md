## 必须保留的行为与组合检查

现行契约归[资产与消息](../../backend/core/message.md)、[数据库文件归属](../../backend/db/README.md)、[模型能力](../../backend/agent/model-capabilities.md)、[工作台文件](../../frontend/workbench-files.md)和[QQ 协议](../../shared/protocol/qqbot-plugin.md)。以下是剩余检查条件，不是已验证结论：

1. 所有权与会话授权独立于物理去重；知道文件 ID 不代表有权。上传归当前身份，提交原子关联会话，子任务只取得明确输入，结果回授可追溯；不同后端只能用户下载后重新上传。
2. 有序 parts、固定资产版本、`original/adapted` 与 `content/reference-only` 在混合输入、分支、历史、导出和渠道投影中一致；仅附文件不自动读取。同名文件不覆盖，适配参数变化不改历史字节。
3. 子任务正式成果采用显式选择或各独立产出链最后成功批次，同批多图保留，中间稿可查；末条只有文字不能丢文件。生成、保存、检查、任务完成、父会话接收和渠道发送分别判断。
4. 浏览器离线时任务仍能执行和回写；子完成后主分支切换、重复终态投递、重新连接不会重复交付，不唤醒用户已停止的任务。投递归正确的会话与代次。
5. 远端成功本地写盘失败只恢复已有结果的下载/保存，不重新生成；结果未知先查询，不能自动补发 QQ 或重新收费。没有可恢复结果时如实报告，不能承诺一定续取。
6. 同标识 ACK 重试只产生一次输入与执行，参数不同时冲突；创建分支成功后刷新失败只重拉，不再次创建。草稿异步结果不能写到切换后的账号、窗口、后端或会话。
7. 两窗预览同一版本关闭其一不能破坏另一窗；子会话删除后主成果引用仍保护文件。草稿、排队、在途和试用引用有效时不得清理；最后引用解除后按已采用延迟清理，认领与清理互斥；迁移归属未明文件不删，不以磁盘不足删除有效成果。
8. QQ 入站文件先按认证身份导入资产，输入顺序与来源保留；结果优先平台原生发送，不向外暴露内部路径、永久公开 URL 或未认证资产链接。消息与文件回执、发送未知与明确失败分别记录。
