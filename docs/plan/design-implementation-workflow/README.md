## 已确认的流程选择

1. 设计从整体框架逐层细化到全部功能行为和跨模块约定；不改变约定的函数拆分、局部变量等由 AI 自行安排。
2. 细化发现上层设计有问题时，返回对应层重新设计，重新检查受影响的下游结论，不能沿着有问题的框架继续添加补丁。
3. 讨论期间持续编写和修改文档，计划记录当前结论、候选与未决问题；实施前形成完整、相互一致且经确认的终版，再按授权实施。“最终落实”不限制文档更新次数；后续设计变化时可重新确认并更新终版。
4. 实施遇到需要用户决定的新问题时，暂停本任务整项实施；调查和整理问题可以继续，不能转向其他实现部分绕过暂停。
5. 默认完整设计整个任务；只有用户明确批准才按独立交付部分拆分，共同接口和依赖需提前明确。
6. 现有任务恢复时补齐剩余工作的设计，不在本次逐份改写，也不追溯重做已完成工作。
