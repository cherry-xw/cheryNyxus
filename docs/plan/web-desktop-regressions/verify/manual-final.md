# 最终手动验证手册

## 前置条件

- 使用最终工作树启动 Web，并准备具有已保存设置及 Pet 状态的测试数据。
- 分别准备桌面视口和移动尺寸视口。

## 操作与通过标准

1. 从任务栏打开、最小化并再次激活已存在窗口；窗口状态恢复且不会重复创建。
2. 刷新工作区并打开设置；持久化设置立即可见，初始化状态不闪回默认值。
3. 切换设置标签；内容和指示状态同步，动效不会导致布局跳动或不可操作。
4. 移动并拖拽 Pet；位置更新稳定，释放后投影状态一致。
5. 检查主 Pet 在工作区中的投影；桌面和移动尺寸下均可见且不遮挡关键操作。

## 记录

在 `verify/out/` 保存版本/提交、日期、浏览器、视口及五条工作流的通过/失败结论和必要截图。失败项返回父计划登记新的修正子计划。
