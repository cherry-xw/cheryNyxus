**文档创建时间：** 2026-09-22T00:00:00+08:00

## 目标与边界

为 `update_todo` 建立精确的计划与任务项归属，并在节点树、对话、精简三种工作台模式中展示统一任务进度标记。保留现有桌宠 `TodoPanel` 和历史 `TodoRenderer`；本任务不删除既有任务清单入口，不新增独立数据库表。

## 已确认的交互契约

- 节点树收起时只显示当前任务一行；悬停后当前行保持身份并移动到完整列表的正确位置，其他任务从上下两侧出现；只有当前项显示旋转 loading。
- 节点树任务标记绑定最新计划对应的节点/任务组；旧计划标记退出，历史节点保留。
- 对话模式主 Agent 显示 `X/Y` 和完整列表，子 Agent 只显示 `X/Y`。
- 精简模式默认只在工具图标上显示 `X/Y`，悬停后展开完整列表。
- 多 Agent 的计划按 `sourceChatId` 分开，不合并任务项。
- 协议使用稳定的 `planId` 与 `itemId`；执行节点和工具调用保留归属字段，支持刷新、重连和历史恢复。
