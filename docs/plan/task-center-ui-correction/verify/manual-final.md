# 最终手动验证手册

## 前置条件

- 使用最终工作树启动 Web 和 Electron。
- 准备多个根任务、长名称、长说明、多选项备注、自由回答及已处理/未处理待办数据。

## 操作与通过标准

1. 在深色和浅色主题打开任务中心，检查标题、正文、控件、间距、字号和字重；除标题外正文保持 400，层级清楚且对比度足够。
2. 缩窄应用窗口并查看长内容；标题和操作栏不收缩，正文区域独立滚动，无重叠、截断或不可达操作。
3. 完成选项备注和自由回答流程；输入上下文完整，提交入口明确，结果可回看。
4. 检查桌面及工作台；旧待操作面板和入口不再出现，共享交互、Lite 与节点树相关能力仍可达。

## 记录

在 `verify/out/` 保存版本/提交、日期、Web/Electron、主题和窗口尺寸对应的通过/失败结论及必要截图。失败项返回父计划登记新的修正子计划。
