# C1 树模式虚化节点与撤回入口

**所属总任务：** [排队消息三模式虚化展示与撤回](README.md)

**状态：** 未开始

**复杂度：** 3/5。在现有排队节点投影上加虚化样式、撤回操作入口与撤回后的节点态；需与节点树渲染与样式系统（nodeSkins）对齐，避免破坏已提交节点展示。

**依赖：** B1。

## 范围与非目标

**范围：**

- 基于 `executionGraph.projectInputNodes` / `useTreeGraphProjection` 现有排队输入投影，给排队（`queued`）用户消息节点加「虚化/实体」视觉区分（虚化=未采用，实体=已消费/已响应）。
- 排队节点提供撤回入口（调用 B1 的 `chat.input.withdraw`）；撤回成功后节点移除或显示取消态。
- 首条消息保持实体节点位于执行流中；后续排队消息作为虚化节点展示。

**非目标：**

- 不重写节点树渲染引擎；不改消息采用策略。

## 已完成事实

- 树模式已用 `executionGraph.projectInputNodes` 把排队输入投影为瞬时节点；`nodeSkins.skinKeyForNode` 负责节点形态；`closeSubtreeActivity` 是现有唯一把 `pending_inputs` 置 `cancelled` 的路径。

## 剩余步骤

1. 给排队投影节点标注排队态并映射到虚化样式。
2. 增加撤回入口（节点操作区/右键），调用 `chat.input.withdraw`。
3. 处理撤回后节点态（移除或取消态）与失败提示。

## 定向自动验证

- 树投影单元测试补充排队态与撤回后节点态；类型检查。

## 完成标准

- 树模式排队消息虚化显示、可撤回；撤回后不残留；与已提交节点视觉可区分。
