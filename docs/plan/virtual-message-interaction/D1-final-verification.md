# D1 综合验证与用户验收

**所属总任务：** [排队消息三模式虚化展示与撤回](README.md)

**状态：** 未开始

**复杂度：** 3/5。核对三模式联动、多消息连发、停止/恢复、撤回竞态与重启恢复；输出人工验收操作卡。

**依赖：** C 批完成后建立清单。

## 范围与非目标

**范围：**

- 类型检查、相关定向测试、`pnpm docs:check` / `pnpm plan:lint`。
- 输出树/对话/精简三模式的人工验收操作卡：发送后立即显示、虚化区分、撤回、末尾定位、多消息连发、停止/恢复、重启恢复、撤回-消费竞态。
- 全部必要验证通过后进入「待用户审批」。

**非目标：**

- 不做破坏性改动；图片/界面视觉验收按项目约定由用户执行。

## 剩余步骤

1. 汇总 A1-A2、B1、C1-C3 的验证结果。
2. 生成验收操作卡（放 `verify/manual-final.md`）。
3. 用户验收后按计划政策收口：长期事实迁入权威文档，从总入口移除任务并删除目录。

## 完成标准

- 用户逐项验收通过并批准；计划收口完成。
