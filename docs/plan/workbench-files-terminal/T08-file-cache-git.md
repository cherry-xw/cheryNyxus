# T08 文件驻留缓存、批量操作与 Git 工作区

**复杂度：** 5

**状态：** 执行中

## 目标

在不限制用户打开文件数量的前提下，把“已打开记录”和“内存中的文件内容”分开。界面保留全部打开记录，但正文、语法高亮结果和二进制预览只保留少量最近使用文件。补充文件刷新、批量关闭、目录定位、Git 状态和分支切换。

## 当前约束

- 文件引用仍只传递工作区相对路径，不把正文注入消息。
- 文件查看仍然只读，不提供编辑和写回。
- 工作区根目录由当前 chat 的 `metadata.workspace` 决定，所有 Git 操作只能在该根目录内执行。
- 驻留内容缓存默认最多 5 个，当前文件优先保留；淘汰只释放内容数据，不删除打开记录。
- Git 分支切换前如果工作区存在未提交修改，默认阻止切换并返回说明，避免覆盖用户修改。
- 删除状态不在文件树中展示；新增和修改状态需要展示。

## 状态模型

前端维护两层状态：

1. `openedFiles`：路径、名称、类型、打开顺序和目录信息，数量不设上限。
2. `residentFiles`：路径到文件内容的 LRU 缓存，最多 5 项。激活文件固定在缓存中，切换时更新最近使用顺序。

顶部横向 tab 只显示 `residentFiles`；右侧下拉显示全部 `openedFiles`。冷文件从下拉或文件树重新打开时重新读取并进入缓存，必要时淘汰最久未使用项。

## 交互

- 文件 tab 名称后始终显示关闭按钮；鼠标悬浮时只高亮按钮区域。
- 当前文件路径行显示完整路径，右侧提供“复制该路径”和“一键引用该文件”两个无边框文本按钮。
- tab 右键菜单提供：关闭左侧、关闭右侧、关闭其他、关闭当前、全部关闭、刷新当前文件。
- 刷新当前文件重新请求 `workspace.files.read`，不改变打开记录；如果 Agent 已修改文件，查看器显示最新内容。
- 顶部下拉切换任意打开文件，并让文件树展开该文件的所有父目录、滚动到文件行并高亮。
- 左侧文件行显示 Git 修改和新增状态，删除项不显示额外状态。

## 后端接口

新增工作区 Git 查询与切换接口：

- `workspace.git.status`：返回当前分支、可用分支和文件状态。
- `workspace.git.checkout`：在工作区根目录执行安全分支切换；工作区脏时拒绝，并返回原因。

接口必须复用 chat 工作区解析和路径沙箱，不接受任意工作目录。Git 命令使用参数数组调用，不拼接用户输入到 shell 字符串；超时、无 Git 仓库、冲突和命令失败返回结构化用户错误。

- 前端状态与交互：`web/test/workbench/fileReferences.test.ts` 及新增文件工作区模型测试。
- 后端文件与 Git：`test/service/workspace/files.test.ts` 及新增 Git handler 测试。
- 类型检查：`pnpm web:type-check`、`pnpm type-check`。
- 构建：`pnpm --filter web exec vite build`、`pnpm exec vite build --ssr --mode dev`。
- 人工检查：大量文件打开、LRU 淘汰、右键批量关闭、刷新 Agent 修改后的文件、Git 分支切换和脏工作区提示。
