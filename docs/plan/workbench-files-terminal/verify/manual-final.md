# 工作台文件与 Terminal 人工验收

**文档创建时间：** 2026-09-19T17:20:00+08:00

每条操作不超过 1 分钟；预先准备有关联工作区的测试会话。状态与反馈回填到 [T07](../T07-verification.md)，此清单不表示已执行。

## 真实视觉与交互

- [ ] 节点树、对话、精简分别输入 `/`、`@`、`&`，确认候选可见，方向键选择、Enter 插入、Escape 仅关闭候选。
- [ ] 用 `&src/` 查找子目录文件，插入含空格路径，发送后显示为文件引用；检查消息仅含路径。
- [ ] 三种模式分别打开文件列表，展开目录、刷新、打开两个文件、关闭单个标签，确认路径和只读内容正确。
- [ ] 在文件行或查看区点击引用，返回对应模式输入框；再次打开文件面板，原标签仍在。
- [ ] 一轮消息结束后确认节点树输入区打开；有审批/提问时等待处理；手动关闭后同轮不再次打开。
- [ ] 首次打开节点树确认整体偏上，悬浮面板有下方空间；手动平移仍可用。
- [ ] 本机 Terminal 输入只读命令，验证 Enter、Tab、历史方向键、Ctrl+C、清屏、断开及重新连接。
- [ ] 测试 SSH 主机使用正确凭据和管理员提供的指纹连接；另一次用错误指纹验证提示与拒绝连接。

## 主观使用体验

- [ ] 首次用户可从提示理解 `/`、`@`、`&` 的区别，以及文件只读、Terminal 命令可修改文件。
- [ ] 本机目标与 SSH 目标清楚可辨，SSH 连接不会让用户误以为左侧文件树已切到远程目录。

## 跨设备、窗口与无障碍

- [ ] 窄窗口和深浅主题各检查一次文件树、标签、菜单和 Terminal，确认必需操作可见。
- [ ] 使用键盘聚焦文件引用按钮和连接表单；必填内容不完整时连接按钮禁用，说明可找到。
- [ ] 返回会话再打开 Terminal，输出仍在；关闭整个工作台或切换会话后，连接释放。

## 性能体验

- [ ] 打开含大量条目的目录并加载下一页，滚动和输入仍可操作。
- [ ] 打开较大文本和不支持的二进制文件，确认有截断或不可预览说明，界面仍响应。
- [ ] 运行较多但有界的终端输出后断开，确认界面恢复；Windows 后台进程清理必须另行解决 T07-F02。
