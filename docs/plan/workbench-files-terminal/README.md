# 工作台文件引用与 Terminal

**文档创建时间：** 2026-09-19T15:18:41+08:00

**状态：** 待综合验证

## 目标

为节点树、对话和精简三种工作台模式提供同一套 `/` 指令、`@` 角色、`&` 文件输入能力；增加当前会话工作区的文件树、只读多标签查看器和一键引用；完成本机与 SSH Terminal 的统一交互和安全边界。

文件引用只保存工作区相对路径并在 Agent 执行时按需调用 `read_file`，不把文件正文自动注入用户消息或模型上下文。Terminal 运行在后端主机或显式配置的 SSH 目标上，与当前工作区文件树分开标识。

## 范围与依赖

- 节点树相机偏上定位与响应结束后的输入区默认打开。
- 三种输入入口共用候选菜单、token 序列化、键盘操作和工作区状态。
- 当前会话工作区懒加载文件树、文本/代码/图片只读查看、多 tab、关闭和一键引用。
- `workspace.files.*` 文件列表/读取接口，以及本机和 SSH Terminal 会话接口。
- 复用现有 `read_file` 权限与脱敏边界、`secretStore` 凭据池、WebSocket RPC 和 xterm 渲染器。

不在本任务中提供文件编辑、文件写回、自动提交文件内容快照或无确认的远程主机连接。

## 完成标准

- 三种模式输入 `/`、`@`、`&` 均能打开正确候选窗口，token 可保存、恢复、发送和显示。
- `&` 引用只传递受工作区约束的路径，Agent 按需调用 `read_file`；越界、删除、权限和无工作区均有明确错误。
- 工作区文件树、文件路径、多标签只读查看、图片预览、敏感文件脱敏和一键引用可用。
- 响应结束且当前根没有待处理审批/提问时，节点树输入区按规则打开；节点树首次定位位于窗口偏上且 hover 内容可见。
- 本机 Terminal 和 SSH Terminal 支持连接、输入、输出、resize、关闭、超时清理和失败提示；SSH 主机指纹与凭据边界生效。
- 自动验证与人工验证分别登记在 T07；未执行的真实 UI 和终端体验检查不得标为完成。
