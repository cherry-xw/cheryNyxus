# 轮次档位人工验收操作卡

## 前置条件

- 启动工作台并打开一棵有多轮会话的 Nyxus 节点树。
- 准备或选择包含内部工具/协作步骤的已结束轮次，以及一轮纯问答轮次；如方便，再选一轮有待处理操作或错误的会话。

## 操作卡 1：已结束轮次与三段式详情

- **入口：** 工作台右侧节点树的折叠档位按钮。
- **操作：** 选择“轮次档位”，悬停或点击一个带内部步骤的已结束轮次节点。
- **期望：** 树上节点仍是无文字的 40×40 图标；详情中依次可见“用户提问”、左轮内部步骤和“最终结论”，最终结论来自主 Agent 最后一条回复。
- **结论：** 通过 / 失败 / 待补 fixture

## 操作卡 2：左轮选择和纯问答轮次

- **入口：** 轮次档位下的轮次节点详情。
- **操作：** 在有内部步骤的轮次中切换左轮成员，再打开一个没有内部步骤的纯问答轮次。
- **期望：** 左轮切换时中段成员详情随之变化；纯问答轮次仍显示提问和结论，中段左轮不出现空壳。
- **结论：** 通过 / 失败 / 待补 fixture

## 操作卡 3：进行中和错误轮次

- **入口：** 轮次档位下包含待处理操作、运行状态或错误步骤的轮次。
- **操作：** 查看运行/等待/待处理轮次及已结束错误轮次。
- **期望：** 进行中或仍待用户处理的内容保持直接可见，不被整轮藏起；已经结束且含错误的压缩轮次节点明显标红。
- **结论：** 通过 / 失败 / 待补 fixture
