- 展示提案版本、参与者反馈、依据、未决异议、替代关系和生效状态。
- 按契约 emit 查看依据/处理提案事件；传递提案 ID 和版本，不仅传显示标题。
- 不统计投票生效条件、不推导裁定权限、不把关闭会议显示为通过。
- 禁止修改数据库、公共协议、权限、业务状态机、RPC 注册和应用装配；禁止直接编辑总进度。
- 只实现明确完整产物，不新建只有透传用途的 container，不额外安装依赖。
