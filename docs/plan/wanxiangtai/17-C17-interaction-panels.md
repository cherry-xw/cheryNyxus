## 定向测试

- 操作前可理解结果，不需要猜测归档、退役或应用的含义。
- 界面发出的目标是明确实例、交付或版本，不仅是显示名。
- 动作失败保持可恢复状态且不显示虚假成功。

新增定向测试入口：`web/test/wanxiangtai/interactions.test.ts`。使用现有 Vitest，不另引入测试框架。该文件为实施目标，目前尚未创建。

```text
pnpm exec vitest run --config web/vitest.config.ts web/test/wanxiangtai/interactions.test.ts
pnpm web:type-check
```

定向测试必须验证对外行为及失败后果，不只复写实现细节。全量检查由批次与最终回归统一记录，不把局部通过当综合通过。

## 完成标准

- 用户可在万象台完成整条工作流并追溯依据。
- 四步均已完成，定向验证有真实结果；产物与模块文档一致。
- 交接实际文件、接口/数据版本、运行命令、已知限制和受影响下游。
- 失败时保留可追溯证据，不通过默认成功或忽略错误掩盖问题。

- 执行前核对前置任务已完成且契约版本一致；当前状态“未开始”，未解锁不等于发生故障。
