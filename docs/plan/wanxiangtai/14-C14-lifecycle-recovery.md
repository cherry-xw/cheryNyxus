- [ ] 1. 实现运行状态、展示位置、可执行资格分别管理；休息室仅接收没有任何未完成责任且非当前对话位的空闲实例。

## 定向测试

- 视觉归档不删除历史、交付或工作区。
- 组长无退役权；用户结束后历史只读。
- 恢复不重复外部工具副作用，不复活已撤销权限的实例。

新增定向测试入口：`test/wanxiangtai/lifecycle-recovery.test.ts`。使用现有 Vitest，不另引入测试框架。该文件为实施目标，目前尚未创建。

```text
pnpm exec vitest run test/wanxiangtai/lifecycle-recovery.test.ts
pnpm type-check
```

定向测试必须验证对外行为及失败后果，不只复写实现细节。全量检查由批次与最终回归统一记录，不把局部通过当综合通过。

## 完成标准

- 无孤儿等待、错误复活或资源预留泄漏。
- 四步均已完成，定向验证有真实结果；产物与模块文档一致。
