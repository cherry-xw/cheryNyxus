## 目标、范围与决定

用户已批准本轮设置与常规文件交互结束，将服务端工具未完成事项独立移交。目标是正确表达当前连接的能力与验证状态，按实际顺序保存正文、思考、服务端工具及受保护续接，完整完成图片提问或搜索后有依据的回答。已确认 ST01—ST13、当前实现与外部证据归[设计与验收](design.md)，不把局部工具完成等同于整个任务通过。

已选择保留本地 `senseCalls` 执行/审批结构，新增独立 `serverToolCalls`，不重复审批或执行服务端已完成调用。该决定继续有效，不重新选择结构；具体持久化与投影边界见[已确认决定](design.md#存量契约改动方式已确认决定)。现行正式说明归[Provider](../../backend/agent/provider.md)、[消息](../../backend/core/message.md)及[模型能力](../../backend/agent/model-capabilities.md)。

接手人为恢复本任务的执行者，复杂度 4/5：跨协议事件、凭据隔离、多轮和恢复，需要协议与持久化分析能力；沿用已确认模型，不分配其他执行者。

## 授权与必须保持的限制

- 当前只做文档移交与本地提交，不推送、不部署、不启停、不改实际配置、不请求模型、不发 QQ、不启动浏览器或读图。
- 既有已确认需求和代码实施决定保留；恢复时先查下表中尚未解决的设计/技术前置，满足开工条件后才能继续依赖实现，不自行补造供应商字段或业务规则。
- GLM、GPT 既有付费批次均已用完或关闭；MiniMax 本批 3 次已用完，不挪额度、不重试、不生成新图，旧 5 元限制已取消但不授予调用权限。
- 不重测已有覆盖的网页读取、Python 或 Shell；GLM 网页读取有成功证据，GPT 的 Python/Shell 实际为不支持，网页出现工具事件但内容抓取失败，不得写成通过。只有新的具体授权才能验证未完成多轮。
- 原生视觉与服务端辅助视觉分开，图片默认含首次采用保留 1 用户轮、过期不删历史、自动补描述默认关闭。视频无本地素材，按已确认范围跳过，不制造素材。
- 共享工作区其他任务的有序消息、图片处理、上下文和 QQ 修改不得覆盖；设置保留媒体入口、独立 Tab 标题层、仅手动刷新工具记录及推荐按钮。
