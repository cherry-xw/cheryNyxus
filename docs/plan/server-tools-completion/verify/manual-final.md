## 用户界面操作

以下项目待 A2、A3 准备好后由执行者提供具体会话入口，不要求用户自行创建测试数据。每项约 1 分钟，可分批反馈编号和通过/异常。

| 编号 | 用户最少操作与预期 | 当前结论 |
| --- | --- | --- |
| U1 | 打开指定会话，展开工具卡：能看出由模型服务执行、真实名称、完成或失败状态及来源；没有本地批准或重试按钮，正文和工具顺序可理解 | 阻塞：指定会话尚未准备 |
| U2 | 刷新页面并重开同一会话：正文、工具、来源及顺序不丢失、不重复；此操作不重新请求模型 | 阻塞：依赖 U1 数据准备 |
| U3 | 打开 `default` 或 `SC05-GPT` 的能力说明，手动刷新工具记录：原生图片能力与服务端辅助看图区分，目录说明、已观察和已验证来源可辨，列表不声称完整 | 阻塞：初始“尚未验证”已具备查看条件，但已观察/已验证记录尚待 A3；GPT 服务端能力查询当前为未知，不伪造目录支持 |

收到反馈后，执行者核对保存记录和接口，定位异常并提供最少复验步骤；没有反馈的项目不记通过。SC05 全部必要项满足后仍需用户批准结束。
