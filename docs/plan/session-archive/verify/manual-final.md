# 会话归档人工验收

## 前置条件

- 使用含一个主 Agent、至少一个子 Agent及一个继续或解释分支的测试会话；另准备一个运行中会话。
- 同时打开两个客户端窗口，用于检查生命周期同步。
- 分别在深色、浅色主题及窄窗口下检查一次归档页。

验收仅使用测试数据；永久删除的归档无法恢复。

## 操作与预期

1. 在工作台归档非运行中的主会话。确认框应说明整组影响；确认后整组从舞台和另一个窗口消失，并在“设置 → 归档”出现。
2. 尝试归档运行中会话以及单独操作子 Agent/分支。界面应提前禁用可判定的运行中入口，服务端应拒绝其他非法目标，不改变历史。
3. 在归档页搜索子 Agent 的角色、摘要或 ID，并切换预设筛选和分页。命中子项时保留完整父级路径；切换筛选或页码后清空当前选择；全选只覆盖当前页主会话。
4. 从主 Agent、子 Agent和分支分别打开“查看对话”。历史内容应完整且只读，不出现继续执行或切换主流程入口；返回设置后，未保存设置草稿、筛选条件和列表位置仍保留。
5. 分别执行单组和当前页批量永久删除。确认信息应给出主会话与关联会话数量；成功项立即从两个窗口消失，刷新后不再出现，失败项保留并可重试。
6. 检查深浅主题、键盘焦点、窄窗口换行和长名称/长错误文案。控件不得重叠或溢出，正文可读，所有操作反馈可找到。

## 证据

在 [综合验证记录](../verification.md) 中写入执行日期、执行人、每项通过或失败结论。需要截图时由用户保存到 `verify/out/`；该目录只存本地验收产物，不提交版本库。
