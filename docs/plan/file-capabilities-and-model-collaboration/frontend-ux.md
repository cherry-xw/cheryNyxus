## 2. 页面归属与导航

```text
设置
├─ 大脑：连接信息 + 原生输入/输出/工具调用
├─ 预设 → 编辑角色：角色装备 + 文件处理方式与实际能力
├─ 器官
│  ├─ 工具组：现有工具分组与权限
│  └─ 文件服务：服务列表 + 当前服务表单 + 试用
├─ 技能：元信息与依赖；角色内显示是否满足
├─ MCP：现有连接设置 + 工具能力及文件输入说明
└─ 全局 → 文件与上下文：上传、携带、保留与默认版本

工作台 / 快速发送
├─ 输入：文字、文件、指令、角色与工作区引用
├─ 任务过程：理解 / 生成 / 委派 / 等待 / 保存结果
├─ 结果：文件预览、下载、来源、用于下一条消息
└─ 上下文详情：本次携带文件及未携带原因
```

从角色的“去配置服务”跳到器官→文件服务，保留父级全部草稿、原角色和滚动定位；返回后刷新草稿能力预览。仅跳转不保存。跨页保存仍只有底栏一个入口。全局页继续位于现有页签末尾。

提供从角色连续完成“选择/创建服务→分配所需工具→设为首选”的操作；所有修改进入同一设置草稿，一次保存。分配动作受现有权限限制，用户不需要抄工具标识或到三个页面重复填连接参数。

## 3. UX-S01 大脑原生能力（F01）

**目标：** 让用户知道当前对话接口本身会什么，而不是误以为开关能安装能力。

1. 选择大脑后先显示连接与模型，后显示“模型本身支持”。输入图片/音频/视频/PDF、文件输出和工具调用分组，行中有名称、状态及来源。
2. 来源为“目录推荐”或“手动设置”；未知显示“尚未确认”，不是灰色勾选框暗示不支持。行旁 info tip 解释影响。
3. 编辑选择“使用推荐 / 支持 / 不支持”。使用推荐值未知时仍显示未知。适配器未实现时说明“当前接口尚未实现”，不能显示可用勾号。
4. 换模型或协议重新计算能力及不兼容提示；保留仍适用的手工字段，不悄悄清除角色工具或附件。语义变化加入保存影响预览。
5. “测试连接”只证明对话请求成功；能力行不因测试成功全部变绿。服务试用入口在文件服务页。

模型列表允许手填新ID；沿已支持协议选择参数，可手动声明能力并显示未验证。使用推荐与显式未知分别保存；修改型号不自动把全部推荐值变成手工覆盖。当前协议没有实现的能力仍不可启用。

**开发注意：** 共享解析结果、草稿计算版本和运行版本分别标识；不得在 Vue 内再写一套能力推导。**易错：** 图标无文字、生成/编辑合并、未知显示不支持、切协议保留过期测试结果。**验收：** 同一个模型改成不支持文件的协议，能力说明即时变化且保存后的运行判断一致。

## 4. UX-S02 文件服务列表与编辑（F02、F03、F04）

### 列表

- 器官页增加“工具组 / 文件服务”二级切换，不改变其他一级页面顺序。
- 文件服务子页采用列表与当前项编辑区。列表显示名字、模型/适配器、已启用操作、启用状态；不在列表重复全部连接参数。
- 顶部搜索按名称/模型/操作，新增按钮始终可找到。无数据时显示“还没有文件服务”与“添加服务”，正文一行说明它用于理解或生成文件。
- 新增先选服务类型，再显示对应表单；新项进入父级草稿并立即选中。取消新增仅撤销本次未保存项，不能丢其他草稿。
- 改名保持选中和引用；复制生成新 ID 并标未保存，密钥仅复制引用。删除后选相邻项，最后一项删除后回空态。

### 字段顺序与条件

| 区域 | 控件与操作 | 展示/隐藏和校验 |
| --- | --- | --- |
| 基本信息 | 名称输入、启用开关、适配器选择 | 名称必填；类型切换列出会被移除的不适用参数，确认后更新草稿，不调用服务 |
| 连接 | 复用已有连接/大脑，或独立填写模型/接入点、地址模式及类型化认证 | 引用型与独立型互斥；地址支持基础地址和高级完整端点覆盖，显示实际端点；认证按适配器提供，本地可无需认证，密钥不回显值 |
| 操作 | 支持的操作列表及启用开关 | 文生图、参考生成、编辑、理解分别命名；不支持的操作显示原因而非可勾选 |
| 默认参数 | 数量、尺寸模式、比例/宽高、质量、格式、背景等 | 只展示该模型有官方依据的字段；两种尺寸模式互斥；缺省标“由服务决定”而非猜值 |
| 执行限制 | 排队超时、单次执行超时、并发数 | 分别注明起算时间和单位，不混同上传大小或上下文 token |
| 使用情况 | 工具组、角色的只读引用列表，可定位 | 未引用可保存并标“尚未分配给角色”，不能暗示主角色已有能力 |

MiniMax 人物参考以“人物参考生成”显示，不写“任意图片编辑”。只有 live 模型显示风格/权重；切回普通模型清除对应提交参数但告知用户。OpenAI 模型的参数选项由适配器目录提供，未确认限制有明确状态，不让界面显示一套通用假枚举。

Google Gemini/Imagen、OpenAI Images/Responses 图片工具、豆包/Seedream、MiniMax 共用上述流程，均属于本次交付范围。厂商提供预设，协议选择映射唯一适配器字段，模型独立选择；不保存两份可能冲突的协议设置。切换厂商时说明哪些参数不再适用，保留通用任务意图但不偷换含义。对话式图像输出可同时展示文字和多张图片，专用生成接口不强行作为聊天角色。开发中尚未完成适配的对象显示真实状态，不能当成完整交付。

### 检查与试用

- “检查配置”只做本地/后端结构和引用校验，结果文案为“配置检查通过，尚未调用服务”。
- “试用”打开当前编辑区内的试用面板：先选操作，输入提示/问题，添加必要参考文件，展示这次模型、数量与参数；实际按钮叫“生成测试图片”或“测试图片理解”。按钮附近直写会调用真实服务，费用以服务方为准，不逐次增加额外审批层。
- 试用使用点击时的草稿快照，不自动保存。修改配置后上次结果标“来自先前配置”，不覆盖新配置状态。
- 试用有进行中、成功、部分成功、失败和结果待确认状态。结果可下载；试用文件属于试用记录，不自动发进当前聊天。关闭面板不等于取消请求，停止按钮独立处理。
- 服务详情可重新查看试用记录并删除；删除解除该记录的文件引用，其他会话已经引用的文件仍保留。草稿试用以独立记录和配置快照归属当前身份，服务未保存也不能丢失成功成果。

**开发注意：** 校验错误绑字段路径；连接错误显示脱敏详情；异步结果绑定 serviceId、配置指纹、requestId。**易错：** 测试点击就保存，网络错误反复重试生成，服务字段变了仍显示绿色成功，试用结果串入聊天。**验收：** 两个服务切换编辑与试用，结果始终回到原服务快照。

## 5. UX-S03 工具组、MCP 与引用（F04、F08）

- 工具组保留现有添加与移除方式；服务生成的工具显示“服务名 · 操作”，info 内容包括接受格式、产出、限制和来源。
- 未启用服务或断开的 MCP 工具仍保留已有引用，显示不可用原因，避免保存草稿时工具悄悄消失。
- 普通工具的 accepts 只表示可接收，不自动标成“图片理解”。MCP 的通用工具若没有明确映射，仅可按其原接口调用，不列为自动处理候选。工具详情提供结构化映射编辑/检查：输入文件、问题、常量、传输方式及结果字段；Web 和 AI 使用相同 schema。
- “配置服务”从标签详情定位文件服务；工具组删除继续用现有确认组件，列受影响角色。可撤销的单个标签移除不增加二次确认，但最终保存校验引用。
- 远程 MCP 所需的文件访问方式在详情说明：可传字节/服务商上传引用/已有受控传输的哪一种；不能显示本地路径就算已经可用。仅接受公网URL而当前没有传输方式时明确不可用，不自动公开文件。

**开发注意：** 工具稳定标识与展示名称分开；配置和当前连接状态分开。**易错：** 断线删除用户配置；显示“支持图片”却不知如何传图；MCP 参数映射只凭同名字段猜测。**验收：** MCP 断开再连接，原绑定保留、可用状态随真实连接变化。

## 6. UX-S04 角色能力与首选方式（F05、F06）

角色详情的工具装备之后放“文件处理方式”。每一行：操作名称、当前方式、执行对象、状态、编辑入口。展示两种来源：“模型直接处理”“工具/角色处理”；不把委派能力贴成模型原生能力。

点击“更改”展开当前行，其他行保持可读。方式为自动、模型直接处理、指定工具、指定角色、关闭；候选列表按当前草稿和预设计算。不能使用的候选显示具体原因，不能只禁用不解释。toolCall 不支持、角色不在预设、权限不允许、缺少凭据、目标服务未启用分别反馈。

多个候选时可以配置首选，或由有工具能力的 A 调用时明确选目标；只有必须在 A 请求前完成的选择才询问用户。优先级和自动规则见配置 C04。关闭表示禁止该角色执行这一已识别操作，直接工具调用不能绕过。选角色后显示委派路径；同操作自动循环报错，不把不同操作的合法互助一概拒绝。

角色默认与当前预设覆盖分开显示，覆盖项提供“恢复角色默认”。同一公共角色可在两个预设选不同对象；局部修改不影响其他预设。默认在当前预设不可用显示缺项，本地显式失效引用保存时定位错误。

没有候选时显示“添加文件服务 / 配置工具组 / 将角色加入当前预设”中实际适用的入口。跳转前保留编辑草稿；返回重新计算，用户不需重新选当前角色。修改方式不触发试用或生成。

角色技能列表用简短状态显示“已满足 / 缺少图片生成 / 可选检查未配置”；详情展开具体依赖与对应能力行。不得在角色卡、装备卡、依赖详情重复堆叠相同说明。

**开发注意：** 后端计算草稿能力，响应携带版本；失效响应丢弃。**易错：** 全局角色列表代替可派发成员；绑定即授权；公共角色误用另一个预设能力；用户改方式即覆盖所有角色。**验收：** 同一公共角色在两个预设展示各自真实候选。

## 7. UX-S05 技能与现有流程（F06、F30）

技能列表保持高密度和分页，默认仅显示“需要 N 项能力”及缺项数，不加载全部正文。查看元信息显示必需、可选操作。全局技能页未指定角色时写“请在角色内查看是否满足”，不能全局标可用。

角色装备技能后在角色能力区检查；缺依赖允许保留配置，但明确调用技能前报告必需缺项，不启动依赖缺失的步骤，也不挡住普通聊天。可选项缺失仅跳对应步骤。导入不安装服务或自动增权；实际文件格式/数量还需运行校验。既有组合技和流程使用同一依赖定义；明确先确认或必须检查的要求进入本次任务条件，使用现有提问/等待，不新增流程编辑器。

**开发注意：** frontmatter 校验、列表分页和工具 schema 同步；可选依赖不阻止核心功能。**易错：** 自定义元数据只是展示却宣称运行检查；不选角色就说可运行。**验收：** 缺少可选检查时能生成但清楚标未检查，缺少生成时不能虚报成功。

## 8. UX-S06 全局文件策略（F07）

全局页增加“文件与上下文”区，分“上传保存”“模型携带”“图片版本”三个小节。普通用户先看到默认值与单位；格式/数量/字节/轮次之间的关系放邻近 tip，不重复大段页面说明。参数和默认值以配置文档 C06 为准。

修改保留轮次时说明“影响后续模型请求，不删除历史文件”。0 显示“不自动携带已完成的历史附件”，未结束任务的必要输入仍按预算处理。上传、输入请求、生成输出限制分别展示；不再设置独立新增5项限额。图片适配可配置最长边和编码质量，原始文件不变。大小输入用MiB、保存bytes；本地估算和实际账单区分，未知显示无法估算。修改只进草稿，不重跑历史处理。

**开发注意：** 单位转换、整数范围、字段间关系在共享 schema 校验；不能用空字符串写成 0。**易错：** 0 被当默认、上传 MiB/MB 混用、降低上限删除现有文件。**验收：** 降低携带上限只影响新请求，旧历史仍可下载。

## 9. UX-S07 保存、离开和冲突（F08、F09）

| 起点 / 动作 | 即时反馈 | 完成/失败与恢复 | 开发注意与易错点 |
| --- | --- | --- | --- |
| 编辑字段 | 标未保存；能力预览标草稿 | 切 Tab 保留；关闭沿现有草稿确认 | 子页卸载不能清空父级草稿 |
| 点击保存 | 固定提交快照，按钮显示保存中且防重入 | 成功只推进该快照基线；继续编辑的内容仍未保存 | 不用响应覆盖点击后新编辑 |
| 字段校验失败 | 字段内报错、底栏计数和定位 | 跳对应 Tab/资源/字段，草稿保留 | 不只显示统一“配置错误” |
| 引用影响需确认 | 用现有影响确认显示对象与等待采用策略 | 取消保留草稿，确认提交同一快照 | 不默默删除关联；不为加字段新增重复确认 |
| 外部窗口/AI 保存 | 提示服务器版本已变化 | 重新读取前保留草稿，展示差异后选择再提交 | 不静默刷新盖掉用户输入 |
| 已保存、等待采用 | 显示等待对象及原因 | 自动更新真实采用事件；用户无需反复保存 | 不显示全部成功，不强制断线重连 |
| 采用失败 | 保留已保存事实及当前仍用的版本 | 定位错误，修正后提交新版本 | 不声称磁盘也回滚了 |
| 点击关闭 | 无草稿直接关闭；有草稿沿既有确认 | 焦点返回打开设置的入口 | 保存中遵循现有关闭限制；Esc 不取消后端任务 |

## 10. UX-S08 AI 自动配置（F09）

用户说“让 A 规划、B 画图”时，AI 流程为：读取现有资源→给出直接服务或角色协作的实际方案→只询问缺少的服务/凭据/目标信息→按既有配置确认规则展示差异→增量保存→读取采用结果→报告已配置内容与未验证项。

已有可用服务优先复用，不按角色名新建同功能服务。敏感值由设置页录入或现有凭据入口处理，聊天只传引用。AI 回复应能定位到服务和角色设置；点击进入目标项，不丢当前草稿。

失败分类：字段错误由 AI 修正；权限不足说明授权范围；版本冲突重新读取再核对；缺少凭据提示用户配置；真实服务未经试用就写“配置已完成，服务调用尚未验证”。AI 配置不代表允许它自动生成付费测试图。

**开发注意：** 模型可见工具定义要含全部新操作与字段、发现结果、保存和采用状态；沿用现有确认而非新增审批产品。**易错：** schema 丢新字段、成功提示省掉等待采用、AI 说配置成功但 Web 找不到资源。**验收：** AI 建立的服务、关联和策略能在 Web 原样编辑。

## 11. UX-C01 添加与编辑文件（F10—F15）

### 入口与定位

- 树输入面板、对话底部、精简底部、快速发送都提供同义“添加文件”，不强迫用户切到树视图管理附件。
- 文件选择支持多选；拖入仅在当前输入区显示接收边界；粘贴图片进入文件流程，普通文字仍粘贴文字。拖拽是补充方式，不能成为唯一入口。
- 有序编辑器在光标处插入文件引用块，展示“附件 1 · 文件名”；下方紧凑列表负责上传、版本、预览和移除。两处共享同一 parts，不产生两份独立排序。
- 上传完成顺序不改变插入顺序。删除引用块只删除该位置，管理条“移除此文件”才删除本草稿内全部对应引用并说明；文件列表按资产/版本汇总。编辑器支持撤销/重做和显式复制引用，不新增富文本格式工具栏。恢复已失效暂存引用时提示重新选择，不伪造可用。
- 每处引用可选择“本次使用内容/仅附文件”，改变当前引用不覆盖其他位置的模式。仅附文件本次不调用模型或工具读取，后续明确要求时可使用。

### 文件行与状态

| 状态 | 行内信息与可用动作 | 发送规则 | 易错与恢复 |
| --- | --- | --- | --- |
| 待上传/上传中 | 文件名、大小、真实进度或“上传中”；取消 | 当前提交包含未完成文件则不可发送 | 无真实进度不造百分比；取消只取消该项 |
| 已上传、可处理 | 缩略图/文件图标、名称、处理方式；预览、移除、版本 | 可发送 | 不能把“已上传”写成“模型已读取” |
| 已上传、仅附文件 | “本次不读取内容”；无处理方式时说明原因；配置入口、移除 | 可发送，模型只收到未读取说明 | 不删除已上传文件，不假装回答内容 |
| 上传失败 | 具体原因；重试、移除 | 需用户重试成功或移除失败项再提交 | 部分成功的其他文件保留，不要求全量重传 |
| 超当前模型限额 | 列超限项和来源；选适配版、分次或仅附文件 | 本次使用内容超限时不可提交，不能悄悄裁掉 | 仅附文件不触发内容读取 |
| 缺失/无权读取 | 文件名和不可用说明 | 可移除或重新选择合法文件 | 不以 0 字节占位当上传成功 |

### 原始与适配版本

点击文件“详情”展开尺寸、格式、大小、来源、当前采用版本和预估用量。只有真实存在派生版本才出现版本选择。原始文件必须是原字节；适配版本明确是否缩放、转格式或改变动画。预览可选择看原始/适配，提交使用所选版本，不把看大图等同切换提交版本。

版本切换不重上传原文件，不修改历史已发送消息。转换失败保留原始文件并给出原因；原始超接口限制时不能冒充适配成功继续调用。透明度/动图无法保留的转换必须显式说明并由用户选择，默认不做有损语义转换。

### 焦点与键盘

文件选择返回后焦点回添加按钮或新引用位置；Esc 只关文件详情/预览。引用块可键盘选中、移除；管理列表的预览、版本、移除都可 Tab 到达。删除后焦点到下一项，无下一项则回添加按钮。中文输入法组合期间 Enter 不发送。

**开发注意：** 草稿按后端、窗口、会话、代次隔离；对象 URL 生命周期跟随资产引用；文件状态独立，不用一个 uploading 布尔控制所有文件。**易错：** 粘贴一次插两图、部分失败吞掉成功、读图完成回写到新会话、版本位置错乱。**验收：** 同时选多文件并切换窗口/视图，原顺序、名字、状态和目标准确。

## 12. UX-C02 发送、分支和排队（F11、F13、F29）

发送按钮遵循当前视图的输入行为。只有文字或合法文件引用都可提交；空消息不可提交。点击后固定 parts、目标 chatId、clientMessageId 和选定版本。ACK 成功清除本次快照；失败保留草稿。ACK 成功后模型失败显示已发送消息与运行错误，不能重新把原消息当未发送而重复提交。

运行中允许输入排队时继续沿现有队列语义；文件跟着该条输入一起排队，不提前交给上一条任务。撤回排队输入解除相应消息引用，但不删除其他消息共享资产。输入运行后不可假装撤回可以取消所有外部副作用，改用任务停止。

“从此处继续”和“解释该节点”扩展 parts 协议；继续成功切到新分支，解释成功保留原工作台目标并显示子分支。创建成功但刷新失败只重拉新分支，不重复创建。

**开发注意：** ACK 与运行完成分开；发送中新编辑进入下一份草稿；快捷发送同样处理未知目标。**易错：** 双击创建两个任务、分支消息丢文件、子会话局部选择被自动改回主会话。**验收：** 请求超时后用同 clientMessageId 重试只出现一条消息。

## 13. UX-C03 理解、生成和委派过程（F16—F24）

- 普通聊天不常驻展示整套能力表；发生文件处理时在对应工具/任务行显示“读取图片 / 生成图片 / 绘图角色处理中 / 保存文件”。
- A 直接使用服务时显示工具调用；委派 B 时沿现有角色卡显示任务与文件数量，详情内列输入文件、要求、当前操作和输出。
- 默认留在 A 的会话；“查看 B 的过程”打开现有详情，关闭回原位置。查看过程不改变下一条消息的发送目标。
- 状态由真实执行阶段决定：排队不是已生成，远端返回不是本地已交付；无真实进度时显示阶段名称，不生成百分比。
- 生成与检查是独立状态；“未检查”不等于生成失败。任务要求必须检查而检查未通过时，文件仍可下载，任务显示尚未满足要求。
- 支持继续修改已选图片；没有指定且有多个可能对象时明确选择，不盲取最后一张。默认不额外检查；已要求检查的任务使用真实视觉处理，自动返工只在授权范围与现有循环上限内执行。
- 多图比较显示联合处理的输入，无法联合理解时明确限制。只有图片无文字时默认描述内容，不能自行开始生成或编辑。
- 多图部分成功显示“已保存 2 张，1 张失败”，成功图可以使用；“重试失败项”明确范围。保存失败按钮叫“重试保存结果”，不能重发生成。
- 厂商无法精确续作某一项时，按钮说明是新生成请求，不伪装恢复；结果未知先查询，无法查询显示由用户决定重新生成。远端结果已过期或从未取得时，不提供保证成功的重试保存。
- “停止”向本次操作/任务传取消；立即显示“正在停止”。远端不支持取消时说明已停止等待但可能仍生成，不承诺费用撤回。
- 关闭或最小化界面不停止任务。重新打开从服务端读真实状态；断网期间显示状态未更新，不冻结成永久运行或自动重新生成。

**开发注意：** 工具/任务/运行/文件状态分别保存，显示模型统一归并；用户停止与系统等待分开。**易错：** 子任务被循环上限暂停却标完成；B 最后说“完成”便丢掉工具图；取消结果晚到覆盖停止状态。**验收：** 关闭浏览器后完成 B→A 返回，恢复只显示一次结果。

## 14. UX-C04 成果、预览与下载（F21、F22、F25）

结果按消息 parts 顺序展示。图片用可点击预览，文件卡显示原名、格式、大小；常用动作“预览 / 下载 / 用于下一条消息”，来源与处理详情进入展开区。生成图名可由系统给可读默认名，不用 UUID 当主标题。

主会话的交付消息拥有结果卡；A 随后纯文字引用同一输出时不重复画廊，显式再次交付或新版本仍显示。最终文件来自正式成果选择，未选择时按每条独立产出链的最后成功版本采用，保留多个方案并标系统采用；中间稿可在任务详情查阅。来源显示角色/工具、参考文件及检查状态，模型描述不能当作未经检查的事实标签。

图片点击预览完整内容，默认 contain，不裁切关键信息；同条结果可切换多图。下载默认原始结果，另有派生版本时清楚命名。文件存在但预览不支持时显示“无法在此预览，可下载”，不当成文件丢失。

预览按既有层级打开，键盘 Esc 关闭，左右键切图，焦点返回原卡；下载和引用按钮不冒泡打开预览。移动/触屏能发现动作，不依赖 hover。图片没有可用说明时用文件名作为替代文本，不生成虚构 alt 描述。

**开发注意：** 读取认证与当前后端绑定；懒加载、尺寸占位、失败替代内容；URL 回收不影响其他视图。**易错：** 临时 URL 过期导致历史丢图，鉴权 query 泄漏，下载重复触发预览，加载新图跳走阅读位置。**验收：** 刷新/重连后可下载同一字节内容。

## 15. UX-C05 用于下一条消息（F26、F28）

1. 工作台内点击时目标为该操作所在视图的输入草稿：对话模式用当前局部会话，树/精简用所属窗口任务，不能读取全局活跃窗口代替。
2. 来自全局历史或归档、目标不明确时，显示目标选择器：后端、窗口/预设、会话可辨识。不同后端本次不提供自动复制，提示先下载再在目标后端上传。
3. 校验资产存在与权限，加入相应草稿并定位引用块；反馈“已加入〈会话名称〉的下一条消息”。不自动发送，也不立刻调用模型。
4. 同一资产/版本已在目标草稿中时定位已有项并提示，不再加一项。发送中的草稿不可变，操作进入下一份草稿。
5. 目标切换或原窗关闭导致请求失效时，不把资产加进其他窗口；显示重新选择目标的入口。归档会话不直接续写。

**开发注意：** 命令携带显式 target、assetId、variant；不再使用无目标的 window 广播。**易错：** 同一点击加入两个窗口、size 用 0 伪造、按文件名解析 ID。**验收：** 同时打开两个预设窗，只在点击来源指定的目标出现附件。

## 16. UX-C06 上下文文件说明（F17、F27）

沿现有只读“查看上下文”入口增加文件明细，不再建平行统计弹窗。选择本次请求后列文件名、采用方式、版本、估算用量和是否实际携带；未携带显示“超保留轮次 / 超预算 / 接口不支持 / 已使用理解结果”等真实原因。

点击文件行只查看元信息与已保存处理记录，不读新图、不调用模型。需要重新使用时回到历史的“用于下一条消息”，此面板仍保持只读。供应商实际 usage 与本地分类估算分开，无法拆分的图片费用不分摊出虚假数字。

**开发注意：** 使用实际请求计划的快照；当前配置不能重算过去请求事实。**易错：** 页面打开触发图片理解、历史图显示在当前请求里、未知用量补零。**验收：** 连续纯文字轮后旧图未再携带，但历史卡与下载仍存在。

## 17. UX-M01 三视图、窗口及生命周期（F28、F29、F32）

| 场景 | 必须保持的结果 | 开发注意 / 常见错误 |
| --- | --- | --- |
| 树↔对话↔精简 | 同一目标的文字、文件、版本、上传状态保持 | 共用草稿状态，不能各保存一份附件列表 |
| 对话模式查看子会话 | 输入明确显示子会话目标；树/精简任务身份不变 | 与现有局部 conversationRootChatId 对齐 |
| 切根会话 | 保存原目标草稿，再显示新目标草稿 | 异步上传回写必须带原身份与代次 |
| 最小化/关闭窗 | 在途任务继续；已发送内容持久；未发送草稿沿当前内存约定 | 关闭前有未提交内容按既有确认；不是后端取消 |
| 刷新浏览器 | 对未提交内容沿现有提醒；重新加载已发送消息/文件/操作 | 草稿只内存保存，不虚构跨刷新恢复 |
| 更换后端/账号 | 所有查询和引用按新身份重新验证 | 旧端文件 URL/操作结果不得写进新端草稿 |
| 归档历史 | 可查看下载；重新引用到活动草稿 | 不能复活归档任务触发生成 |
| 删除任务 | 沿现有确认；其他任务仍引用的文件保留 | 资产引用计数不等于子会话拥有即删除 |

活跃草稿和排队输入为文件保留引用，不受无引用暂存24小时清理影响；离开后失效保留记录按正式清理策略释放。成果和试用文件随记录保留，磁盘不足显示明确错误，不暗中删文件。QQ/NapCat 等渠道复用同一资产和任务规则，优先原生发文件，不能发送时提供原因及现有受认证入口，不发内部assetId或永久公开链接。

## 18. 通用错误文案与焦点（F34）

| 原因 | 页面内文案方向 | 操作 |
| --- | --- | --- |
| 缺少能力 | “文件已保存，当前角色没有读取此格式的方式” | 去配置 / 仅附文件 / 移除草稿引用 |
| 多个候选 | “有多个可用处理方式，请选择一个” | 打开当前操作的方式选择 |
| 凭据缺失 | “此服务未配置有效的密钥引用” | 定位凭据字段；不显示密钥值 |
| 服务未连接 | “服务当前不可用”加实际原因 | 重试连接/查看设置；不自动删配置 |
| 超限 | “此操作最多…，当前…”并注明限制来源 | 调整版本/数量/范围 |
| 文件缺失 | “此文件暂时无法读取” | 重试读取 / 重新上传；不显示空图冒充成功 |
| 结果未知 | “请求已发出，暂时无法确认服务结果” | 查询状态；明确重新生成是新请求 |
| 版本冲突 | “配置已被其他窗口或 AI 修改” | 重新读取并核对；草稿保留 |

错误就近显示并能换行；诊断详情可展开复制脱敏原文，不只用几秒 toast。结果通知不抢焦点。设置错误定位主动聚焦字段；关闭弹层回触发按钮；按钮消失时回所属区域标题或添加入口。只在用户启动的操作完成后播报简短状态，流式进度不逐 token 播报。

## 19. 开发交付检查

每个设置/会话交互都必须有空、加载、成功、失败、不可用、并发变化和离开返回的处理；不能以只实现正常状态结束。UI 不直接访问 transport；controller 经 application public 接口触发用例，纯状态转换放 model。配置草稿、资产、操作和任务各有唯一状态维护者。验收逐项使用[验收矩阵](acceptance.md)，不以读源码判断视觉已经通过。
