## 3. 布局与信息层级

### 设置文件服务

宽窗口采用“资源列表 + 当前服务编辑”，列表仅承担查找与选择。编辑区顺序为名称与状态、连接、操作、参数、使用情况；检查/试用动作靠近连接与参数，不占全局保存位。使用小节标题和分隔线，避免每个字段外包一张卡。

资源列表宽度以名称可辨识为目标，建议 `clamp(180px, 24%, 240px)`；编辑区最低可用宽度约 360px。容器不能同时满足时转为单列“选择服务→编辑”页内切换，保留返回、搜索和选中状态，不把两列硬挤到 360px 窗口。该数值是本次布局起点，最终须用户视觉验收，调整不能通过缩小文字实现。

表单在可用空间足够时两列，窄时一列。地址、完整错误和说明独占一行；模型/数量等短字段可并排。宽高作为同一尺寸模式的一组，不分散到页面不同角落。标签在控件上方或沿已有一致标签列，不在相邻字段来回切布局。

### 角色能力区

采用紧凑行列表：操作→方式与执行对象→状态→更改。需要更改时在本行下方展开选择区，避免跳出多个叠加弹窗。窄宽度时执行对象和状态换到下一行；操作名称与更改按钮仍可见。依赖说明只在缺项行和详情出现。

### 输入与成果

编辑器中的引用块显示编号/名字；下方管理条显示缩略图或文件图标、上传/版本状态和动作。多附件可换行或在条内滚动，不带动整个窗口水平滚动。管理条不能挤没文字输入和发送按钮。

成果区按文件实际比例展示；缩略图可以限定框但应使用 contain 呈现整张图。下载/用于下一条消息以可读动作显示；窄窗动作换行，不能藏进只有 hover 才出现的角落。大量结果分页或按需加载，保留数量与“还有 N 项”的明确入口。

**开发注意：** 按容器尺寸而非屏幕宽度布局；不固定内容卡高度；长错误完整展开。**易错：** 两栏仍各给 min-width 导致外层溢出、附件抢走发送区、固定高裁掉结果。对应 F10、F25、F28、F35。

## 4. 颜色、字体与几何

| 项目 | 具体要求 | 禁止的误用 |
| --- | --- | --- |
| 主文字 | `--ink`；辅助使用现有混色，不靠低透明度把重要状态变不可读 | 普通文字用 `--accent-ink` 放在白底 |
| 主要动作 | 所在界面 accent + 实心反色；同一区最多突出一个下一步 | 每个按钮都实心高亮；“检查配置”比保存更抢眼 |
| 状态 | 成功/警告/错误/信息对应语义 token，并有文字/图标 | 仅颜色区别“未验证”和“可用” |
| 设置分类 | 继承已有 Tab 色，保留属性页样式 | 将器官页绿色当作“成功”语义 |
| 字体 | UI 用 `--font-ui`；代码、标识和端点用 `--font-mono` | 整段中文提示等宽；用粗体代替布局 |
| 字号与字重 | 设置表单/正文 14px，辅助至少 12px；工作台适配 +2px 基线；正文 400，真实标题≤600 | 通过 10–11px 放下更多字段；状态、参数值连续加粗 |
| 圆角 | 新按钮、输入、卡片、弹层直角 | 因 `--radius-control` 存在便沿用圆角 |
| 边框与间距 | 边框用 `--border/--border-strong`；控件间距优先 8px，面板约 14px，依现有密度调整 | 大阴影和层层大卡片代替信息层级 |
| 文件图像 | 透明图底色可辨识；图片原色不随主题滤镜改变 | 为适应深色给图片反色/增亮，误导生成效果判断 |

正文目标对比度 4.5:1，必要图标/边界 3:1。开发负责依据正式主题实现可读配色和焦点，不能把CSS计算或布局排错责任转交用户；用户确认实际浅深主题下的渲染与交互。静态token核对不代表实际视觉已验收。新代码尽量不用硬编码前景色；专属色按正式规范处理深色覆盖。

## 5. 组件映射

以下为建议组件职责名，实施可按现有目录最终命名；不能通过机械拆文件引入只有透传的组件。

| 组件/用例 | 承担的内容 | 复用或替换入口 | 开发与易错点 |
| --- | --- | --- | --- |
| 原生能力表 | 名称、三态、来源、覆盖 | 替换 `MediaCapabilityGrid` 的旧理解/生成二义性 | 不自行计算后端支持能力 |
| 文件服务编辑器 | 当前项表单、检查和试用 | `SensesTab` 子视图 + `TabShell` | 父级草稿；卸载不丢编辑；类型字段完整校验 |
| 角色能力列表 | 首选、来源、缺失依赖 | 角色工作台现有装备区域 | 同一 public role 在预设上下文不同；不缓存成全局可用 |
| 文件引用编辑与管理条 | 有序引用、上传、版本、移除 | 共用 composer 与 `MediaThumbStrip` | 保持单一 parts 状态，不能编辑器和列表各自排序 |
| 文件卡 | 名称、类别、状态、动作 | `MessageParts` 按顺序渲染 `AssetCard` | 普通文件不落到音频分支；不在模板请求资产 |
| 文件详情 | 原始/适配元信息、来源、理解记录 | 现有详情/媒体查看器容器 | 懒加载；打开不调用模型；完整错误可读 |
| 操作结果 | 阶段、输出、部分失败、重试 | 现有工具渲染与角色结果 | 不把 runtime 状态从多处 boolean 拼出来 |
| 指定草稿引用用例 | 校验目标后加入下一条消息 | 替换无目标 `bringMediaEvent` 广播 | command 带后端/窗口/会话/资产身份；公开 application 接口 |

只在两个真实使用点共享的纯展示控件才移到公共组件；资产和任务业务不塞进无归属 utils。新增控制器经 application public port，状态归所属 store，纯格式化/状态计算在 model。

## 6. 控件状态与可发现性

| 状态 | 视觉与交互要求 | 易错点 |
| --- | --- | --- |
| 默认 | 真实 label、必要单位、明确动作 | 用 placeholder 代替 label；只有图标无名称 |
| hover | 轻背景或边界强调；不是唯一动作入口 | 移除/下载只在 hover 可见，触屏无法使用 |
| focus-visible | 明确焦点边界，不能被 overflow 裁掉 | 重置 outline 后无替代；卡片内 tab 顺序和视觉相反 |
| selected | 边框/位置/选中标记与颜色并用；ARIA 同步 | 只靠绿色或翻转表示启用 |
| disabled | 外层 tip 说明原因；重要阻塞同时行内显示 | disabled 按钮自身收不到 hover，用户不知为何不能点 |
| loading | 保持按钮宽度；有准确动作文字；防重复提交 | spinner 让布局跳动；全页禁用妨碍查看/取消 |
| success | 明确“已上传/已保存/已生效/已交付”是哪一步 | 一律写“成功”掩盖后续未完成 |
| error | 靠近操作、全文可换行；可恢复入口 | 只在底栏计数，不能定位字段；5 秒后错误消失 |
| unknown | 使用中性标记与“尚未确认/结果待确认” | 灰掉当不可用，或写 0/失败伪造事实 |

图标按钮须有可读名称和 tip；说明遵循 info+tip 优先，关键阻塞直接在页面内表达。tip 支持换行、键盘进入和触屏查看，Teleport 的主题样式来自明确容器/类，不依赖偶然 scoped 继承。不用原生 title 承担文件处理、取消、下载等重要解释。

## 7. 层级、键盘与返回位置

- 设置继续由已有桌面窗口承载，不套第二层窗口标题栏；文件试用优先页内展开。
- 图片预览与文件详情使用统一 overlay layer；节点树内部详情遵守 `--nx-z-*`，不能随手写巨大 z-index。
- Esc 从最上层弹层关闭，不顺带关闭设置或取消后端任务；关闭后焦点返回真实触发项。
- tab 页保留现有方向键、Home/End；自定义二级页签同样有 tablist/tab/tabpanel 对应关系。
- 文件动作使用真实 button/link；卡片可预览时提供可聚焦按钮，不只给 div 加 click。
- 重要状态可用礼貌播报，连续进度不打断用户；文件名过长换行或提供完整详情，不能只给不透明缩写。

**易错：** 设置试用的确认层被主窗口遮住；关图时把聊天也关了；删除后焦点留在已移除 DOM；Enter 在中文输入法中误发送。对应 F34。

## 8. 动效与性能

本任务不新建装饰动效。切 Tab/展开/关闭复用现有 transition 与 `MOTION` 语义；高频文件选中、移除、版本切换直接反馈即可，不增加 3D 翻转或每次入场动画。状态变化优先文字和静态图标。

精简动效偏好下取消位移和循环装饰，功能状态完整保留。图片加载前预留尺寸避免滚动跳动；不为每张缩略图启动独立帧循环；音视频不自动播放。仅加载可见预览，历史分页不一次取所有原图。

上传/试用/预览的监听、对象 URL、取消信号在所属组件/用例生命周期释放；关闭一个预览不能 revoke 其他视图仍使用的 URL。页面不在前台时暂停非必要动效，不暂停后端实际任务。

## 9. 响应式验收尺寸与内容

测试尺寸是检验场景，不是固定产品布局参数：最小工作区窗 360×260、窄窗约 600px、普通桌面约 960px、宽桌面及最大化；还需缩放至 200%、长中文/英文文件名、长错误、20 个附件、多服务列表。

每一档都保留：当前对象、主要内容、文件动作、保存/发送、关闭、错误和恢复入口。先隐藏装饰、再单列和换行，不能缩字或裁内容。高宽都不足时内容区滚动，底部主要操作仍可到达；不能为了固定底栏让短窗口内容高度为负。

对应 UX-S01—S08、UX-C01—C06、UX-M01，视觉验收由用户逐项完成；开发遵循现有浏览器和读图权限，提供准备好的验收环境与步骤。组件职责名称和布局起点可按现有实现调整，不改变已确认行为，也不逐像素重复要求用户批准。
