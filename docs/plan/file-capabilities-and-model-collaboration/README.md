## 完成标准

1. Web 与 AI 配置得到相同的实际能力、缺失原因及生效状态。
2. 主角色能直接调用文件工具或带文件委派其他角色，不把纯生成模型伪装成聊天角色。
3. 文件保存、历史展示和模型输入分开；工具与子任务返回结构化文件，不从回复 URL 猜文件。
4. 上传、固定版本预览/下载、重新引用、重启恢复与权限有效；旧图按轮退出，显式读取可恢复。
5. 服务端工具独立记录调用、结果和来源；失败与未知状态不报成功，本地调用遵守原授权。
6. 配置、模板、说明与验证同步。离线通过不代替真实接口、QQ、生产依赖及人工验收。
