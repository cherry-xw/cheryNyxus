## 1. 配置与能力

| 编号 / 功能点 | 交互点 | 开发注意点 | 易出问题的错误点 |
| --- | --- | --- | --- |
| F01 模型真实能力 | 大脑页按输入、输出、工具调用显示支持状态及来源，允许明确覆盖推荐 | 按模型、协议、实际适配器共同判定；能力未知可保存，但不当成可执行 | 把工具能力写成模型能力；换协议仍显示旧能力；勾选不能实现的输入后静默丢附件 |
| F02 文件服务配置 | 器官页的“文件服务”子页新增、选择、编辑、停用、删除服务 | 每个服务独立稳定 ID；类型决定字段与操作；调用参数由适配器校验 | 复用聊天端点调用纯绘图模型；改名使角色引用断开；服务未启用仍显示可用 |
| F03 凭据与连通检查 | 引用已有环境变量；刷新列表；分别提供检查配置和实际试用 | 凭据仅后端解析；配置检查不调用远程模型；实际试用明确调用对象与参数 | 密钥进消息/日志；“保存成功”当成“生成已验证”；只测聊天端点就认证绘图可用 |
| F04 工具声明 | 工具详情列出准确操作、输入格式、输出格式与限制；服务生成的工具可加入工具组 | 普通、自定义、MCP、服务工具统一声明；普通工具不能仅靠 accepts 被前置调用 | “可接收图片”误等于“会看图”；通用生成误等于编辑；按工具加载顺序挑第一个 |
| F05 角色能力来源与首选 | 角色默认与预设覆盖分开；列出操作、方式、来源，可选原生/工具/角色或关闭 | 能力从实际配置计算；首选绑定不授权；关闭的操作不能被其他已识别调用入口绕过 | 所有角色都当作可派发；同操作自动转交循环；把不同操作合法互助误判循环 |
| F06 技能依赖 | 技能详情显示必需/可选能力；在角色内显示满足、缺失或待配置 | 依赖是结构化元数据；正文仍教方法；强依赖缺失时不得宣称技能可完整运行 | 加载技能自动增权、装工具；可选检查能力缺失导致整个技能不能使用 |
| F07 上下文策略 | 全局页“文件与上下文”编辑上传与携带上限、保留轮次、默认版本 | 与服务商限制取更严格值；显式引用不绕过大小/格式限制 | 把文件存储上限等同模型请求上限；普通聊天不推进旧图退出；清理上下文误删文件 |
| F08 保存、生效与回滚 | 共用设置底栏；区分草稿、保存、等待采用、采用失败；可定位错误 | Web、AI、手工加载用同一校验；资源影响加入现有配置协调器 | 子页自行落盘；保存中继续编辑被 ACK 清空；回滚旧结构直接破坏新运行态 |
| F09 AI 自动配置 | 用户自然语言要求配置；AI 发现已有资源、提出必要差异、提交并报告实际结果 | 补齐读取目录、验证、增量修改和状态查询；保留现有配置权限与确认行为 | AI 猜 API、工具名或密钥；Web 有字段而 AI schema 漏字段；并发覆盖用户草稿 |

## 2. 输入与文件保存

| F11 文图混排和发送 | 文件插入当前光标，显示编号与名字；文字和附件按编辑顺序提交 | 单一有序 parts；草稿、发送快照、持久消息一致；保持指令/角色/工作区引用语义 | 所有图片附在最后导致“上图/下图”错配；删除文件残留隐藏引用；UI 顺序与 API 不同 |
| F12 原始与适配版本 | 文件详情选择“原始文件/适配版本”，显示大小、尺寸与预估消耗 | 原始字节不可变；派生文件记录父文件与转换参数；透明图、动图不偷偷破坏语义 | 把压缩图叫原图；前后端重复压缩；切版本只改预览没改实际请求 |
| F13 草稿、取消与重复发送 | 上传中可取消单项；失败项可重试/移除；发送失败保留草稿 | 草稿按后端、窗口、会话、草稿代次隔离；服务端 ACK 后清理提交快照 | 切会话后迟到上传写到新会话；移除草稿删除历史文件；断线重试重复发消息 |
| F14 工作区文件引用 | “引用路径”与“附加文件快照”名称区分；目录只能引用路径 | 路径引用仍按工作区权限按需读取；快照导入才生成资产；文件改变不重写旧快照 | 把服务器路径当成浏览器文件；发送目录即批量上传；后续文件改变导致历史内容变化 |
| F15 普通文件格式 | 文本可读；PDF 走支持的原生接口或工具；办公/二进制依处理矩阵 | 保存和下载通用；提取、转换结果标出范围；不执行文档脚本或宏 | 以扩展名假装已经理解；截断不标记；扫描 PDF 当成空白；将 HTML 原样执行 |

## 3. 理解、生成与协作

| 编号 / 功能点 | 交互点 | 开发注意点 | 易出问题的错误点 |
| --- | --- | --- | --- |
| F16 逐附件处理 | 文件详情显示“模型直接读取/由工具处理/委派/仅附文件”及原因 | 按文件判断方式，同一多文件比较问题联合处理；限制、取消、权限统一检查 | A支持图片就跳过同轮音频；拆成独立摘要冒充联合比较；批结果重复进入上下文 |
| F17 独立理解记录 | 消息详情可查看谁处理、处理什么问题、是否成功；后续可继续问 | 保存文件版本、问题、处理版本、范围与结果；重复投递复用同一操作 | 永久缓存一段摘要回答所有新问题；把工具文字当用户原文；失败结果当缓存成功 |
| F18 直接生成图片 | A 调用已配服务；会话绘图的模型、张数和参数见 UX-C07，不跳服务商页面 | 纯生成模型作为工具的执行对象；本次参数固定；D21—D22 的原生多图与上限按 C07 | 为纯生成模型创建无法聊天的子 Agent；重复单图或多个子 Agent 凑数；把最多张数当出满保证 |
| F19 参考图与编辑 | 使用选定资产及明确操作；支持范围由服务决定，详情显示参考文件 | 区分文字生成、参考图生成、编辑；不支持蒙版的服务不能接收蒙版操作 | 人像参考模型被宣称任意编辑；忽略多张参考图；尺寸/比例参数冲突 |
| F20 角色委派 | A 向 B 指派任务，显示角色、要求、输入文件和详情入口 | `spawn_role` 传明确文件 ID；复用现有任务身份、等待策略与归属 | 把全父历史复制给 B；权限外附件泄露；主会话偷偷切成 B |
| F21 文件结果返回 | B结束后主会话显示可下载文件；A可汇总或继续处理；用户选图/反馈/定稿流程见 UX-C07 | 子任务正式交付仍按各独立产出链最后成功批次，同批多图保留；用户定稿独立记录见 D04 | 只取末条文字；只留最后一张；中间稿或系统自动交付冒充用户定稿 |
| F22 生成、检查、交付分开 | 显示“已生成/未检查/检查通过或未通过/已返回”；只有要求检查才执行 | 检查必须记录真实视觉模型或工具及依据；用户可直接查看未检查结果 | 不能看图的 A 声称已确认内容；检查失败把成功生成文件隐藏 |
| F23 后台执行与恢复 | 关闭窗口任务继续；重新打开读取状态；停止是独立动作 | 启动、写回、父续跑不依赖浏览器；任务认领、完成投递防重复 | 关闭页面后 B 不启动或 A 不续跑；重连又生成一次；前端与后端同时恢复重复运行 |
| F24 失败、部分成功与重试 | 多图部分成功保留成功项；失败操作可查看原因及重试范围 | 生成已成功但保存失败只能重试保存；发送结果不明先查操作记录 | 点“重试”重新扣费生成全部；超时声称远端已取消；HTTP 200 的业务错误当成功 |

| F28 多视图与多窗口 | 树/对话/精简具备相同文件动作；局部对话目标不改变窗口主流程 | 共用用例和数据，外观分别适配；操作目标快照贯穿异步调用 | 精简视图附件无法管理；跨后端串文件；查看子会话时发给主会话 |

| F30 技能与流程使用 | 现有技能/组合技可声明依赖并调用相同文件工具；缺项可跳配置 | 普通 A/B 协作复用现有调度；明确“建议步骤”和系统保证的固定步骤 | 把技能正文当可强制执行的流程；另建功能重复的流程系统 |

## 5. 能力组合的明确结果

| A 的实际能力 | 已配置对象 | 预期行为 |
| --- | --- | --- |
| 可调用工具，不能看图 | 图片理解工具 | 保存图片，由工具带用户问题理解，把有来源的文字结果交给 A |
| 可调用工具，能看不能生成 | 图片生成服务 | A 直接规划并调用服务；根据任务需要选择是否检查结果 |
| 可调用工具，不能看不能生成 | 可生成图片的 B 角色 | A 委派；B 按需要用参考图，返回正式文件；A 文字汇总、系统展示 |
| A 能看图，B 仅有生成 API | 生成服务 | A 看图与规划；B 作为工具服务接收提示和允许的参考图，不启动 B 聊天循环 |
| A 不能看图，B 能生成但不能看 | 生成工具，可选第三方视觉工具 | B 可生成/使用其 API 支持的参考输入；未配置检查时标未检查，不伪造验收 |
| A 不支持工具调用 | 系统配置的文件前置理解方式 | 后端在 A 请求前处理输入；A 仅接收结果文字；不声称 A 能自主派发 |
| A 不支持工具调用且无处理方式 | 无 | 文件可保存和交付给人；模型请求带文件存在但不可读取的说明；不发送不支持的二进制 |
| A 原生支持图片但不支持音频 | 音频转写工具 | 同条消息图片原生、音频转写；两者按原顺序进入模型请求 |

## 6. 边界

本任务交付通用文件保存、能力选择、图片理解/生成/参考与支持的编辑、配置与协作；保留现有音视频工具接入并验证混合处理，不把“通用”扩大为内置全部音视频模型和全部办公格式渲染器。

会话绘图补充需求 D21—D23 沿用 F18—F24、F28 等功能编号；已确认设计及技术前置见[配置 C07/D04](configuration-runtime.md#c07-绘图张数与模型限制)，交互见[UX-C07](frontend-ux.md#20-ux-c07-会话绘图与多轮选图)，验收见[绘图补充验收](acceptance.md#8-会话绘图补充验收)。已取得代码实施与离线验证授权，当前暂停原因及恢复条件见[总任务](README.md#当前恢复检查点)；原有适配器存在不代表完整绘图流程已实现。

交付厂商与接口范围以[配置C03](configuration-runtime.md#c03-操作与适配器范围)为准，包含已确认的Google、OpenAI、豆包和MiniMax接口，不以空入口代替适配。Web、QQ/NapCat等现有入口同步接入文件输入输出。内置文本读取和支持接口的原生PDF；OCR、PDF提取及Office转换通过已配置工具接入，真实账号未测试与代码未实现分别标记。

不支持的格式必须有可执行的保存/下载/配置工具路径，不能假装支持。无需新增通用流程画布、图片编辑画布或云存储产品。文件服务适配范围与明确不支持的操作由[配置与执行](configuration-runtime.md)列出。
