- 通用关系不绑定厂商；厂商字段样例和验证脚本只证明相应接口。
- 组件职责名称和布局起点可依实现调整，行为与可读性要求保持，不逐像素重批。
- 规划确认、代码实施、资料核实、真实测试和用户验收分别标记，不互相代替。
