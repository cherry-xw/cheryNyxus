# 手动验证操作卡（精简模式工具展示层重构）

> 由综合验证小任务 T6 维护。用户逐条按卡核对，每条 ≤1 分钟给出结论（通过 / 失败 / 待补 fixture）。
> 仅保留四类事项：真实视觉与交互、主观 UX 判断、跨设备/窗口/无障碍的真实使用、性能体验。
> AI 不截图不读图；证据留存（截图/文字记录）由用户完成。

## 前置条件

- 本地启动 web 前端与后端，进入工作台「精简模式」。
- 准备包含内置工具调用（含 history_recall、stop_child、send_to_child、memory_manage、install_skill、role_acceptance、select_conversation）和一个外部工具调用的会话数据。
