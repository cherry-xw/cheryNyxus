# 前端交互与颜色人工 UI 验收手册

所属总任务：[前端交互与颜色排查](../README.md)。状态：待用户执行。

## 验证职责与边界

本手册集中维护本任务所有尚需人工确认的 UI 项目。自动执行者只运行单元/组件测试、类型检查、静态检查、构建和文档检查；不得启动或操控浏览器/Electron，不得截图、录屏、像素比对或运行浏览器 UI 自动化。程序化 DOM/CSS 检查只能作为代码级回归，不能替代本手册结论。

以下步骤仅由用户在实际界面中执行。用户可以用文字记录结论；如需截图，由用户自行截取并决定保存位置，自动执行者不采集 UI 证据。

## 前置条件

- 使用用户认可的本地前端预览地址和实际 Electron 应用；如只具备其中一个宿主，应在结论中注明未覆盖项。
- 使用可安全修改的测试配置、测试会话和无费用测试数据；不要为了验收启动会产生费用、发送真实消息或破坏现有数据的任务。
- 尽量覆盖浅色/深色、浏览器桌面/Electron 原生窗口，以及正常连接、断连或失败状态；无法构造的状态记录为“未验证”，不要推定通过。
- 发现问题时记录“场景、操作、实际结果、预期结果”；截图不是必需条件。

## 一、主题与颜色

- [ ] 分别切换浅色和深色，正文、说明、按钮文字、输入值、选中项与错误提示均清晰可读；实心强调按钮的文字与背景没有同色或低对比问题。
- [ ] 检查设置页、登录页、会话/资源列表、审批卡片、弹出菜单与确认框的普通、悬停、聚焦、选中和禁用状态；强调色语义一致，分类色没有替代正文或主操作色。
- [ ] 打开会跨宿主 Teleport 的 `/`、`@`、角色、路由或确认菜单；菜单位于当前窗口之上，不被相邻窗口遮挡。
- [ ] 查看 Nyxus 节点树/执行图的节点、边、标签与选中态；浅深主题下连线可辨认，Canvas 切换主题后同步更新。
- [ ] 在两个同源浏览器窗口或相关原生窗口间切换主题；其他窗口同步且不反复闪烁。

## 二、设置、关闭与关键操作

- [ ] 修改设置后关闭窗口，确认可以明确选择保存、放弃或继续编辑；取消关闭不丢草稿，保存失败不显示为成功。
- [ ] 在保存进行中继续修改，完成后界面仍能区分已保存内容与新草稿；外部修订或重新加载不会静默覆盖当前编辑。
- [ ] 分别从页面按钮、窗口标题栏和系统关闭入口测试有/无未保存修改；各入口执行同一关闭策略，最小化不丢草稿。
- [ ] 在会话间切换并发送含附件的草稿；附件只属于原会话，上传延迟完成后不会串入新会话，失败重试保留可恢复内容。
- [ ] 在工作台分支场景检查附件限制、发送前置条件和刷新失败提示；不支持的操作在执行前说明原因，创建成功但刷新失败时给出可恢复反馈。

## 三、登录、连接与反馈

- [ ] 首次打开、已有配置、保存过密码和密码已失效四种情况下，页面说明当前连接目标和下一步；旧密码不会造成静默错误登录。
- [ ] 连续点击登录或连接时只产生一次有效提交；界面等待实际 WebSocket 连接完成后再进入成功态。
- [ ] 模拟断连、连接失败和重试，错误信息可见且给出下一步，重试后状态能恢复。
- [ ] 执行复制操作时仅在剪贴板实际成功后提示成功；审批时间显示与校准时间一致。
- [ ] 正常启动不展示伪造的诊断遥测或固定测量数据；真实失败仍有清晰诊断入口。

## 四、可发现性、键盘、触摸与小视口

- [ ] 首次用户无需开发者解释即可找到连接、选择配置、开始会话、查看执行、处理审批和找回窗口的入口；危险操作前能看到影响范围。
- [ ] 仅用键盘完成设置页签切换、Nyxus 会话选择/删除、弹层确认/取消和主要表单提交；焦点顺序合理、焦点样式可见，删除不会因按键重复触发。
- [ ] 在约 1280×720、768×1024、390×844 及应用允许的最小窗口检查设置、资源工作台、会话列表和输入区；名称、搜索、主要输入和确认按钮不被裁掉且可滚动到达。
- [ ] 使用触摸或不依赖 hover 的方式完成主要操作；仅通过悬停显示的信息同时存在可发现的点击、聚焦或说明入口。
- [ ] 长标题、多会话、空数据和加载失败时仍能辨认对象、状态和下一步；加载失败提供重试，过期搜索结果不会覆盖当前查询。
