# 最终手动验证手册

## 前置条件

- 使用包含计划实现检查点的最新工作树，依赖安装完成，Web 与 Electron 均可正常启动。
- 使用 1920x1080 基准设备，并准备 1366x768、1024x768 视口及 Electron 100%/150% 缩放环境。
- 准备包含长会话、多分支节点、待处理项、历史记录和设置数据的测试账号。

## 操作与通过标准

1. 分别切换深色、浅色、reduced-motion 和 forced-colors，检查桌面、窗口、会话、节点树、历史、设置、Lite 和待操作表面；内容可辨识，无重叠、截断或双重窗口壳。
2. 在三个 Web 视口完成窗口打开、移动、缩放、最小化、任务栏恢复以及各主流程；窗口状态稳定，交互入口可理解且无不可达内容。
3. 在 Electron 100%/150% 缩放下重复原生窗口和核心业务流程；拖拽区、窗口控制和嵌入内容正确。
4. 在高质量档和平衡档运行节点树及环境动效各 30 秒；高质量档交互目标 60fps，平衡档平均不低于 30fps。
5. 反复打开和关闭窗口、节点树与检查器，确认 primitive、ticker 和监听器能够回落，无持续增长。

## 记录

在 `verify/out/` 保存测试设备、版本/提交、日期、各项结论、FPS 数据及必要截图。执行人必须明确写出通过或失败；失败项返回父计划登记新的修正子计划。
