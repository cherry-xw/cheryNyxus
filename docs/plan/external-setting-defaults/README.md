## 核实期间的显示与保存

- 未设置时显示“未设置 · 默认未核实”；显式值照常显示并能查看未核实原因。空白、0、auto 不能冒充已知默认。现有类型、范围及分支校验不放宽。
- 恢复默认只删除用户主动恢复的覆盖；未核实数字直接输入，不能从猜测默认加减。没有实际编辑不补写配置。
- 文件参数按实际适配器、图片型号和生成/编辑操作分别说明；不因默认状态不同新增第二份审核覆盖。Gemini 嵌套参数沿相同上下文。
- MCP env 只说明状态和配置方式，不额外查询或显示变量值；角色缺省 MCP 为 `[]`、估算 0 token 的已确认规则不变。
- 不反复请求同一超时入口，不用模型调用或切换接口代替查资料；没有自动提醒或调度承诺。需要新的外部操作时单独取得具体授权。
