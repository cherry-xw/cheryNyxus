# T03 历史结果与上下文摘要

所属总任务：[主 Agent 运行流程图](README.md)。状态：未开始。批次：B。复杂度：4（较高），因为需保证长期结果、旧数据、压缩生效与冷恢复的一致性。依赖：T01。与 T02 共享 runtime/observer 文件，修改需协调。

## 范围与交付

实现只读 history RPC、主 Agent 历史投影、冻结资源摘要和必要的最终结果附注。交付可以供前端直接播放的关联事实页，不生成逐 token 或逐内部阶段日志。

存储预算及旧数据降级由[技术设计](technical-design.md)第 6、7 节维护。禁止新增追踪表、延长 journal 保留期、批量改写旧消息或为了本图改变 Agent 上下文语义。

## 定向自动验证

执行 `pnpm type-check` 与任务隔离验证入口，覆盖：

- 无 chat/root journal 的长期历史仍可返回主路径；不触发 Agent 创建或运行。
- 完整批次和父子因果关系可恢复；子内部模型/工具被排除。
- skill 加载成功去重，未找到、失败、拒绝不计数；计数允许超过 discoverable N。
- 压缩请求/摘要产生/生效可区分；真实生效才换阶段；重复回调不重复切阶段。
- 冷恢复保留压缩后技能，配置纪元切换按实际消息保留处理，资源取冻结值。
- 旧字段缺失、崩溃窗口、被替换结果、撤回和分页乱序可降级而不伪造事实。
- SQL/结果更新范围只触及必要现有 JSON，不新增表、不修改 retention、不删除历史。

## 完成标准

历史 RPC 提供确定关联的主 Agent 事实；前端不需要解析消息文本猜测归属。资源计数与有效上下文一致，证据缺失被显式表达；定向检查通过。回写实际字段落点、恢复规则与验证入口后删除本文件。
