# T05 基础流程图与实时展示

所属总任务：[主 Agent 运行流程图](README.md)。状态：未开始。批次：C。复杂度：3（中等），因为需要统一节点、动态批次和多个展示状态，同时保持尺寸稳定。依赖：T02、T04。

## 范围与交付

交付 Vue 节点与 SVG 连线的单一 renderer、实时状态消费、工具行、资源与 Hook 摘要，以及必要的连接/空白/错误状态。完整清单和样式见[需求说明](requirements.md)第 2 至 8 节，渲染选型见[技术设计](technical-design.md)第 2 节。

不添加完整详情、流程编辑、节点拖拽、通用图引擎、全量技能/记忆列表或子 Agent 子树。只读 renderer 接受投影状态，供 T06 同样复用。
