## 目标与边界

Vue Flow 在同一画布呈现历史与运行头部：主 Agent 为展开式多层回路，全细节骨架常驻；子 Agent 使用简略头部，保留详细历史。工具调用共用头部处理链，每次实际执行有独立实例。完成实例沉淀为历史，模板保留；各分支独立增长，派发、返回和继续关系使用显式事实。

保留消息、工具详情、审批/提问、折叠、代际与分支操作；不改执行顺序、审批策略或唤醒策略，不另建消息存储。缺失旧历史不伪造。新步骤记录不得包含提示词、参数、结果正文、密钥或原始错误。观察异常不阻断执行。
