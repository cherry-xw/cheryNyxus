## 目标与边界

在工作台增加可展开的主 Agent 运行流程图，展示基础执行结构、当前节点和简要结果，并支持从长期历史记录生成粗粒度回放。保留消息节点树与卡片模式；子 Agent 只显示主 Agent 的派发与回传边界。

## 五档复杂度

复杂度用于后续分配模型能力，不指定模型名称。按状态风险、跨模块依赖和验证难度评估，不按文件数或代码行数评估。

| 档位 | 名称 | 判断标准 |
| --- | --- | --- |
| 1 | 简单 | 局部文字、图标、明确的样式值调整；无新状态或契约 |
| 2 | 较低 | 单组件或单模块的数据映射、有限交互；边界已确定 |
| 3 | 中等 | 多组件布局、流程渲染、前端回放状态；需保持既有交互 |
| 4 | 较高 | 前后端契约、异步等待、订阅恢复、压缩与持久化边界的组合 |
| 5 | 复杂 | 核心执行语义或共享状态机重构，存在广泛兼容与迁移风险 |

本方案主要为 3、4 档。无需凑齐每档任务；若实施演变为修改核心 Loop、构建持久追踪系统或改变历史事实模型，应先重新缩小方案，确实必要再登记 5 档任务。
