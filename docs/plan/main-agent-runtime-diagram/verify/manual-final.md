# 最终人工验收手册

所属任务：[主 Agent 运行流程图](../README.md)。当前状态：待功能实现后执行，尚无实机验证结论。

本手册只在最后的“综合验证与用户验收”阶段执行。操作人默认是用户；未经针对本任务的明确授权，开发 Agent 不启动或控制浏览器/Electron、不截图、不通过程序化 DOM/CSS 检查替代验收。边界见[项目文档配置](../../../standards/global/project-documentation.md)。

## 1. 前置条件与数据

- 后端和 Web 的类型检查、构建与允许的定向自动验证已完成；T01 至 T06 结果已回写任务入口。
- 使用隔离测试工作区和可访问主会话的正常账号/连接；准备 Mock Provider 场景，不修改用户真实业务数据。Mock 使用说明见[测试文档](../../../quality/testing/mock-provider.md)。
- 数据包含：普通主 Agent 问答；同批三个以上工具且有重复名称；自动工具与需审批工具混合；技能加载成功/失败；已注入记忆；子派发及回传；可重试失败；一次成功压缩及其后续消息。
- 准备无新 workflow 附注、短期 chat/root journal 已不可用但长期消息保留的旧历史 fixture，不通过删除真实数据库模拟。
- 准备浅/深主题，浏览器工作台与可用的 Electron 窗口；尺寸使用工作台自身尺寸记录，不只记显示器分辨率。
- 确认用于测试的工具没有不可逆外部副作用；审批测试使用 mock 或测试目录内操作。

## 2. 操作与通过标准

| 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- |
| 默认关闭与入口 | 新开工作台，定位右侧“运行流程”；开关两次 | 初始关闭，按钮状态正确；打开可见当前结构，关闭恢复原空间 |
| 水平上下布局 | 保持水平树，打开流程；改变窗口宽高 | 流程在上且横向，树在下且方向不变；不足时图内横滚/内容纵滚 |
| 三栏共存 | 切换卡片竖向模式，打开流程，翻卡并操作树 | 卡片、树、流程三栏可用，卡片不被重复缩窄；选择状态保持 |
| 窄窗 | 分别检查约 1440、1280、1024、720px 的工作台宽度 | 不足时横向滚动，全部栏可达；工具栏固定，中文可读，不自动关卡片或流程 |
| 低窗与输入区 | 约 480px 高度，展开输入框、附件和较长输入内容 | 必要内容滚动，输入框不遮挡当前流程节点、控制条或卡片操作 |
| 独立视口 | 平移/缩放树，滚动流程，再翻卡；等待高亮变化 | 不发生联动平移或自动 fit；高亮变化不改变树相机与卡片选择 |
| 基础模型流程 | 发送普通输入，观察准备、模型、汇总和循环判断 | 只显示基础节点；当前活动突出，等待模型仍为运行中 |
| 完整工具批次 | 发起含重复工具和审批项的批次，依次处理审批 | 所有调用先列出；逐个更新实际执行状态；同名不同调用分开，已完成本批项保留 |
| 工具溢出 | 使用多于三项调用的批次，手动滚动后让当前项变化 | 列表内部滚动，完整清单可见；不强抢滚动，定位当前图标可用 |
| 派发与回传 | 主 Agent 派发子任务，分别观察等待与继续处理情形 | 工具派发成功不等于任务返回；无子 Agent 内部节点，回传边界清晰 |
| 等待与暂停 | 分别等待回答、审批、子返回，然后执行既有暂停/继续操作 | 等待属于运行中；真实暂停才显示暂停；恢复 pending 工具不伪造模型调用 |
| 错误与重试 | Mock 模型先失败后成功，再测试最终失败/工具拒绝 | 可恢复错误走重试支路；单项失败不提前把主任务设失败；终态明确 |
| Hook 标记 | 使用有前/后 Hook 的模型/工具场景，另试无 Hook 或 stub 场景 | 只有适用位置标记，没有 Hook 名称或执行状态；stub 不冒充有效挂载 |
| 资源计数 | 观察当前记忆/技能数量，成功/失败/重复加载技能，再写入记忆 | 只显示计数；成功正文去重，失败不增加；记忆写入不冒充当前提示词已刷新 |
| 压缩与恢复 | 压缩成功前后观察，随后加载技能并刷新；另试失败压缩 | 生效前不清空；生效后保留骨架与冻结摘要、重置旧正文参与；刷新保留压缩后技能 |
| 配置纪元 | 在安全边界切换已有配置纪元，查看当前流程和历史 | 资源对应真实新提示词；消息保留时不套用压缩清空规则；历史不套当前配置 |
| 中途打开与断线 | 运行中打开流程，断开再连接；关闭一个观察窗口 | 能补现有活动信息；断线标未同步；重连恢复，另一个窗口和真实任务不受观察关闭影响 |
| 主会话切换 | 两个主会话快速切换，在树中选中子节点，再查看只读历史 | 不串状态；选中子节点不改主 Agent 范围；归档历史不被恢复为可执行 |
| 回放控制 | 当前阶段播放、暂停、步进、拖进度、改速度、选择早期阶段 | 顺序动画无需等待真实耗时；阶段与进度正确；控件不能执行业务动作 |
| 回放与实时并存 | 主 Agent 继续运行时回放旧步骤，再返回实时 | 回放不被新帧打断；返回实时看到最新状态；卡片和树选择不变 |
| 旧历史降级 | 打开无短期 journal 的 fixture，回放缺少新字段的阶段 | 仍有主路径；缺失计数/条件步骤标明未知，不补造重试、Hook 或精确压缩证据 |
| 主题与辅助操作 | 浅/深主题、减少动效、键盘聚焦和操作图标 | 图标/短文字可读，颜色不是唯一状态信息，聚焦可见，无叠字和无意义动画 |
| 生命周期 | 最小化后恢复、关闭窗口，再重新打开 | 最小化停止绘制动画，关闭后无残留回放；重新打开默认关闭流程 |

节点数、布局预算和状态判据以[需求说明](../requirements.md)为准。观察到未列出的角落问题时，写明实际触发路径，不通过修改需求掩盖实现问题。
