将已归一化的长期主 Agent 事实变为前端回放帧，提供阶段选择、播放/暂停、进度、速度和返回实时。规则见[需求说明第 10 节](requirements.md#10-实时观察与回放)，映射见[技术设计第 7 节](technical-design.md#7-历史投影与前端回放)。

只播放基础流程，不还原逐 token 或精确时间，不调用业务动作，不另外构建一套图组件。

## 定向自动验证

执行 `pnpm web:type-check` 和新增回放纯函数/假时钟测试，覆盖：

- 同样事实生成同样步骤，回退再前进可得到相同投影；结果顺序不靠真实耗时。
- 同批重复工具不合并，跨页完整清单先于工具执行帧。
- 子 Agent 内部步骤不可进入回放；未知重试/Hook/压缩生效不补造。
- 压缩前后技能参与边界正确，冷恢复后的当前阶段可回放。
- 暂停/跳转/切换阶段/卸载后旧计时器不再更新状态；切回实时能恢复最新帧。
- 所有播放器操作均不调用 chat.send/resume、审批、终止或工具执行 API。

## 完成标准

基础回放可以在无短期 journal 的情况下运行，状态与实时任务隔离，控制行为通过纯函数与假时钟验证。回写实际入口、验证命令和最终回归目标后删除本文件，随后准备 T07。
